# تطوير أقسام الصفحة الرئيسية — 30 أكتوبر 2026

## النطاق

تطوير العربية والإنجليزية للأقسام الأربعة وصفحاتها المرتبطة، مع الحفاظ على النسخة التركية الحالية. تبقى إدارة نشر السجلات من لوحة المحتوى، ولا تُنشأ سجلات إنتاج أو عملاء افتراضيون.

- **القطاعات:** بطاقات ملونة باحتياجات عملية للمنشآت، وصفحة تصفح بفلاترها، وصفحة تفاصيل تضيف نطاقًا أوليًا وروابط إلى أمثلة مناسبة موجودة في الموقع.
- **المشاريع:** عرض بصري للصور المنشورة أو رسم بديل خفيف، مع تمييز المشاريع ذات معرفات `demo-` بشارة صغيرة. تفاصيل الأمثلة لا تعرض شهادة عميل أو بلدًا أو تاريخ تنفيذ بوصفها أعمالًا حقيقية، وتوضح طبيعة النتائج التوضيحية.
- **التقنيات:** أمثلة لأدوات نستخدمها بحسب متطلبات المشروع، منفصلة عن ادعاء الشراكة أو الاعتماد. تُستبعد سجلات الشركاء التوضيحية المعروفة حتى لو كانت موسومة بالتحقق في البيانات القديمة. تبقى سجلات الشركاء الفعلية المنشورة والمتحقق منها قابلة للعرض.
- **المقالات والموارد:** بطاقات بنوع المحتوى وتاريخه ووقت القراءة، وتصفح المقالات والموارد وصفحات التفاصيل. الموارد العربية والإنجليزية لها مسار `/insights/resources/[slug]`، وتحوّل روابطها القديمة تحت `/insights/blog/` إلى المسار الجديد. دراسات الحالة المُدارة بالمحتوى تحتفظ بمسارها القديم لتجنب التعارض مع دراسات الحالة المؤلفة الموجودة.

## ضوابط المحتوى

المحتوى غير المنشور أو المستقبلي لا يظهر. الصفحات المرتبطة تحافظ على تحقق النشر ومعالجة التعذر و404. إذا لم تُنشر صفحة الشركاء فلا تُعرض روابط إليها من قسم التقنيات. لا تستحدث الأمثلة شراكات أو شهادات أو نتائج عملاء. لا تُعاد أي خدمة متقاعدة إلى العرض.

الرسوم البديلة مبنية بـHTML وCSS وأيقونات الموقع، دون تنزيل مكتبة رسوم إضافية. الصور المنشورة تُحمّل كسولًا. الحركة تراعي تقليل الحركة، والروابط تعمل دون JavaScript.

مسارات الموارد القديمة التي تعيدها فهارس API تظل صالحة عبر التحويل؛ لم تتغير قاعدة البيانات أو تعريفات فهرسة API. لا يتطلب هذا التحديث ترحيل بيانات.
