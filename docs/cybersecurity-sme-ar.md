# تطوير قسم الأمن السيبراني للمنشآت الصغيرة والمتوسطة

## التصميم والمحتوى

طُوّرت صفحة الخدمة القائمة `/ar/services/cybersecurity` ونظيرتها الإنجليزية. استُفيد من توزيع <https://www.n-ix.com/cybersecurity-services-provider/>: هيرو أبيض ورسمة على خلفية برتقالية، تنقل داخل الصفحة، فوائد، بطاقات خدمات على تدرج بنفسجي، دراسات، مخرجات ومراحل عمل وأسئلة شائعة.

العنوان العربي «حماية تبدأ من التفاصيل»، والإنجليزي «Security starts with clarity». النصوص والرسوم أصلية ومناسبة لنطاق TEVONIQ، دون نسخ أعمال عملاء المرجع أو نسبتها للشركة أو عرض شعارات اعتمادات أو فرق أو شراكات أو نتائج غير موثقة. لا روابط أو وسائط خارجية داخل القسم.

حوفظ على جميع قرارات إخفاء الخدمات السابقة. لم تُستعد خدمات اختبار الاختراق أو اختبار أمن التطبيقات أو DevSecOps أو استمرارية الأعمال أو التشغيل المُدار أو الخدمات السبع المخفية مؤخرًا، ولم يُستخدم مسار جديد لتجاوز حجبها.

## العرض العملي

ستة محاور محددة: مراجعة الاحتياج والإعدادات، الحسابات والصلاحيات، البريد وإعدادات النطاق، إعدادات أجهزة العمل، الملفات والمشاركة، والتوثيق والتنبيهات والمتابعة. لكل محور مخرج ورابط تواصل يحمل سياقه. يتطلب أي تغيير نطاقًا وإذنًا ومسؤول اعتماد وطريقة تراجع مناسبة؛ لا ينفذ الموقع أي إجراء على بيئة عميل.

الدراسات الثلاث لمنشآت افتراضية: حسابات مكتب، مصادر إرسال متجر، وملفات مشروع. تتضمن المشكلة والنهج والأدلة المطلوبة والمخرج والحدود، وتُعرض تفاصيلها بعناصر أصلية تعمل دون JavaScript. ليست أعمال عملاء أو تقارير فحص حقيقية.

يعرض قسم المخرجات هيكلًا توضيحيًا لتقرير يربط المورد بمالكه والملاحظة والإجراء ودليل التحقق. لا يُقدّم تقريرًا أو درجة حماية عن الزائر. خمس مراحل باختيارات أصلية: تحديد النطاق والإذن، المراجعة والأولويات، اعتماد الخطة، الضبط والتحقق، والتسليم والمتابعة. تظهر جميع اللوحات إذا لم يدعم المتصفح `:has`.

تشرح الأسئلة حدود النطاق وعدم ضمان الحماية المطلقة وعدم منح شهادة امتثال، وتفصل المتابعة المتفق عليها عن وجود مراقبة بشرية أو استجابة للحوادث على مدار الساعة. ترتبط النطاقات المكملة بصفحات الشبكات وضمان الجودة والحلول المخصصة القائمة فقط.

## مرشد الأولويات

ثلاثة اختيارات معتمدة: المحور، المعلومات المتاحة عن الوضع، ومن يستطيع اعتماد الوصول. ينتج 18 تركيبًا بقواعد ثابتة معلنة. تُقدّم معالجة الإذن أولًا، ثم الجرد عند غياب المراجعة، أو ترتيب الملاحظات، أو طلب دليل تحقق للإعدادات القائمة. لا يحوّل وجود إعداد إلى ادعاء كفاية الحماية.

لا يطلب المرشد عنوان نظام أو كلمات مرور أو رموز تحقق أو ملفات. لا فحص أو شبكة أو استدعاء مزود ذكاء اصطناعي أو تخزين اختيارات أو إرسال تلقائي. تُمسح النتيجة عند تغيير الاختيارات، ويعيد زر البداية القيم الافتراضية. تعلن النتيجة لتقنيات المساعدة. يبقى المحتوى والمراحل والدراسات متاحًا دون JavaScript، مع شرح احتياج المرشد إليه.

## التكامل والنشر

يُعرض القالب الجديد عند نشر الخدمة الحالية فقط، وبقيت التركية على القالب السابق. حُدّث ملخص دليل الخدمات وSEO ومعرفة مساعد الموقع تحت شرط النشر ذاته، دون تغيير مزود المساعد أو تعليماته أو معلومات المقر.

تُقبل سياقات `cyber=review` ومعرفات الخدمات والدراسات المعروفة ببادئتي `scope-` و`case-`. يقبل `cyber=guide` قيمًا معتمدة فقط لـ`topic` و`state` و`permission`، ويرفض القيم المجهولة أو الناقصة أو المتعددة. حُفظت أولوية سياقات التواصل السابقة. الرابط يجهز الرسالة ولا يرسلها.

الرسوم HTML وSVG وCSS مع أيقونات النظام القائم. لا صور جديدة أو مكتبات رسوم إضافية أو تحميل نماذج. يحترم الرسم إعداد تقليل الحركة.

نقطة الرجوع `checkpoint/pre-cybersecurity-20261030` تشير إلى `02eeaa4` قبل التعديل. لا تغيير على قاعدة البيانات أو إعدادات الإنتاج أو حالة نشر الخدمة في CMS. رفع التحديث إلى `main` يجهّزه للنشر اليدوي عبر Render.

## التحقق

نجح البناء وفحص ESLint و261 اختبار وحدة. تغطي الاختبارات أولوية الإذن وحالة المعرفة بالوضع، وجميع تركيبات المرشد الـ18، وسياقات التواصل ورفض القيم المجهولة أو المتعددة، ووجود حدود وأدلة ومخرجات لكل دراسة، دون إلغاء سياسة الخدمات المخفية.

نجح فحص Chrome المخصص على النسخة النهائية بالعربية والإنجليزية: شرط النشر، وست خدمات وثلاث دراسات وخمس مراحل مع التنقل بلوحة المفاتيح، وجميع اختيارات المرشد الـ18 لكل لغة وإعادة البداية، وروابط التواصل والتحقق من رفض السياقات غير المعروفة، وروابط النطاقات المكملة وبيانات FAQ المنظمة. شمل عروض 320 و390 و768 و1024 و1440 وaxe A/AA وتقليل الحركة. بقي عنوان الكمبيوتر بسطر واحد داخل عموده في اللغتين. اختُبرت المراحل والدراسات دون JavaScript وبقاء التركية على القالب السابق. لم تظهر أخطاء متصفح أو طلبات تواصل تلقائية أو روابط لخدمات مخفية.

نجحت اختبارات التوافق الـ81 في Chrome، بما فيها دليل الخدمات والتنقل والرئيسية والنماذج والخدمات الحالية، وحجب الخدمات المخفية من القوائم والبحث وخريطة الموقع والصفحات في اللغات الثلاث. جُدّدت ملاحظة بطاقة الأمن في اختبار دليل الخدمات لتستخدم الملخص الحديث دون تغيير عدد الخدمات أو سياسة إخفائها.
