# تحديث صفحة دليل الخدمات

## الصفحة والهدف

الهدف هو تحديث `/ar/services` و`/en/services`، وهما وجهة زر استكشاف الخدمات في الهيرو، لتتوافقا مع أقسام هندسة البرمجيات والاستشارات والأتمتة وERP التي طُوّرت حديثًا. تبقى الصفحة التركية بقالبها السابق.

## التصميم والمحتوى

- هيرو جديد موجه للمنشآت الصغيرة والمتوسطة، بصياغة الشركة وصورة الحلول المحلية الخفيفة، وروابط لاستكشاف الدليل والتواصل.
- أربعة مسارات واضحة: مواقع الأعمال، أنظمة إدارة العمل، الأتمتة والربط، ولوحات المعلومات. تقود إلى معارض النماذج الحالية، وهي نماذج توضيحية ببيانات افتراضية وليست دراسات عملاء.
- دليل الخدمات المنشورة مصنف حسب مجموعات القائمة المنسدلة، بعناوينها وترتيبها الحاليين، وصورة مناسبة لكل فئة وروابط مباشرة لصفحات الخدمات.
- استبدال الرسومات والبطاقات القديمة في العربية والإنجليزية. تستخدم بطاقات الأقسام الأربعة الحديثة أوصافها المعتمدة، مع الحفاظ على عناوين CMS المنشورة وروابطها.
- تظهر الخدمة المنشورة غير المصنفة في القائمة ضمن قسم «خدمات أخرى منشورة»؛ التصنيف لا ينشئ خدمة ولا يعرض مسودة من إعدادات التنقل.
- روابط الفئات أصلية تعمل دون JavaScript. توضح الأعداد الخدمات المعروضة في الصفحة الحالية، وليست أعدادًا إجمالية لكل صفحات البحث.

## البيانات والبحث والترقيم

- يعتمد الدليل على `getServices` وواجهة الخدمات العامة المنشورة. لا توجد قائمة خدمات تجريبية بديلة عند تعذر الاتصال.
- يطلب العرض العربي والإنجليزي حد API المسموح، 48 خدمة في الصفحة، حتى يظهر الدليل الحالي عادة في صفحة واحدة، مع الإبقاء على الترقيم عندما يزيد العدد. يبقى الحد الافتراضي للمستدعين الآخرين والتركية 12.
- جلب بيانات الخدمات والتنقل بالتوازي لتجنب تأخير طلب بعد آخر.
- البحث من الخادم في الدليل كله، ويبدأ من الصفحة الأولى عند تقديم بحث جديد. روابط الصفحات تحفظ مصطلح البحث.
- تُعرض حالات منفصلة لعدم وجود نتيجة ولعدم توفر المصدر، دون إظهار خدمات غير منشورة. أُحدّث اختبار الحالة الفارغة لتعكس رسالة البحث الدقيقة بدل الادعاء بعدم وجود أي خدمات في اللغة.
- تهيئة عنوان ووصف عربي وإنجليزي ورابط canonical، مع استمرار آلية إعدادات SEO المعتمدة.

## الخدمات المحذوفة

تستمر قائمة الاستبعاد المركزية `packages/types/src/retired-catalog.ts` عبر واجهة API وحدود قراءة المحتوى. أُضيف تحقق دفاعي في تجميع الدليل يمنع كل slug أو عنوان أو رابط متقاعد حتى عند تمرير بيانات قديمة مباشرة إلى المصنف. لا تغيير لقائمة الاستبعاد ولا استعادة للخدمات السحابية أو SAP أو RPA أو توسعة الفرق أو البيانات والتحليلات أو الاختبارات الأمنية أو الألعاب المحذوفة.

لم تُحذف سجلات CMS مؤرشفة أو تُعدّل قاعدة الإنتاج؛ الحذف المقصود هنا منع العرض العام. لا تتحول روابط التنقل إلى بطاقات ما لم تصل الخدمة ضمن نتيجة API المنشورة.

## الأداء والتحقق

أُعيد استخدام صور WebP المحلية الموجودة، مع تحميل كسول للبطاقات والفئات، ودون معالجة صور أثناء الطلب. الصفحة الأساسية وتجميع الخدمات والبحث والترقيم تعمل من الخادم ولا تتطلب JavaScript جديدًا.

الفحوص تشمل بناء Next.js والأنواع وESLint وPrettier، واختبارات وحدات للمصنف وكل slugs المحذوفة، وفحوص متصفح للعربية والإنجليزية والتركية المحفوظة، والروابط من الهيرو إلى الدليل ثم إلى النماذج والخدمات، والبحث والترقيم والنتائج الفارغة والانقطاع، وإتاحة WCAG عبر axe والمقاسات 1440 و1024 و768 و390 و320 والعمل دون JavaScript، إضافة إلى الأقسام والمعارض السابقة.

## نقطة الرجوع والنشر

وسم `checkpoint/pre-services-directory-20261028` عند `6f3dc3e` قبل التعديل. يمكن استعادة ملفات الدليل من الوسم في تغيير جديد دون إرجاع أي عمل لاحق غير متعلق به. الرفع إلى مستودع TEVONIQ المعتمد على `main`، والنشر من Render يدوي.
