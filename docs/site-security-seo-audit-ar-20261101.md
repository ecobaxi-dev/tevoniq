# مراجعة الموقع والحماية وSEO

التاريخ: 1 نوفمبر 2026. نقطة البداية: `01708dc`.

## نطاق المراجعة

فحص HTTP للقراءة فقط للموقع المنشور، ومراجعة الكود وإعدادات النشر والاعتماديات، واختبارات محلية معزولة. لم تُرسل نماذج أو رسائل أو طلبات شراء إلى الإنتاج، ولم تُغيّر بيانات CMS أو إعدادات الاستضافة أو قاعدة البيانات. هذه مراجعة تطبيقية وليست إثباتًا لخلو النظام من كل ثغرة أو اختبار اختراق للبنية المستضافة.

### الموقع المنشور قبل نشر الإصلاحات

- جميع روابط sitemap البالغ عددها **274** أعادت صفحات ناجحة، دون 5xx أو روابط معطلة؛ موردان يصلان بعد تحويل إلى المسار الجديد.
- **52** مسارًا عامًا إضافيًا مرتبطًا من الصفحات أعاد 200 أيضًا.
- لم تظهر صور دون خاصية `alt` في HTML المفحوص. لا يعني ذلك تقييم جودة وصف كل صورة أو اختبار تنزيل كل وسيط خارجي.
- جميع صفحات الخريطة لها عنوان وH1 واحد. صفحة الخدمات التركية القديمة وحدها بلا وصف؛ تُترك دون محتوى جديد وفق سياسة اللغة التركية.
- صفحة الإدارة العامة هي واجهة دخول موسومة noindex؛ API الجلسة يرفض الزائر غير المصادق بـ401.
- الخدمة المتقاعدة ومسار اختبار غير موجود يعيدان 404.
- فحص HEAD لمساري `.env` و`.git/config` أعاد 404. لم تُقرأ محتويات ملفات حساسة.
- HTTP والنطاق دون www ينتقلان إلى HTTPS وwww. تأكد وجود CSP بتوقيع nonce، وHSTS، وnosniff، ومنع الإطارات، وسياسة الإحالة.
- أقصى زمن HTTP في الجولة الأساسية كان نحو 2.8 ثانية؛ هذا قياس جلب HTML من بيئة الفحص، وليس قياس Core Web Vitals أو ضمانًا لزمن التحميل.

## الحماية الموجودة التي روجعت

- مصادقة CMS بتوكن عشوائي، وتخزين بصمته في قاعدة البيانات، وكوكي HttpOnly وSameSite=Strict وSecure عند HTTPS.
- فحص Origin لعمليات الكتابة عبر BFF، وقائمة سماح لمساراته، وحارس صلاحيات افتراضي يرفض المسارات غير المعروفة.
- إبطال الجلسات وتغير نسخ المصادقة، ومهلة خمول، وحدود لمحاولات الدخول والإرسال، وسجلات تدقيق.
- حدود لحجم الرفع والتحقق من نوع الملفات ومحتواها ومسارات التخزين، ورفض الملفات عند غياب الفاحص في الإنتاج حيث يلزم.
- استعلامات SQL المراجعة تستخدم معاملات؛ لا استخدام لـqueryRawUnsafe في مسارات التطبيق المفحوصة. نصوص المقالات تُرسم كمكونات؛ JSON-LD يُهَرّب لمنع إنهاء عنصر script.
- الأسرار تبقى في الخادم، وسجلات الطلبات تستبعد الأجسام والاستعلامات والترويسات الحساسة. لم توجد ملفات `.env` فعلية ضمن الملفات المتتبعة، بل أمثلة فقط.
- مساعد الذكاء: فحص Origin وحدود الطلب والسياق والميزانية والوقت، والتوكن في الخادم.

هذه ضوابط كود جرى فحصها؛ لا تثبت وحدها إعداد كل متغير أو خدمة خارجية في حساب الاستضافة.

## ما يحتاج متابعة تشغيلية

1. **تنبيهات أدوات التطوير:** بقيت 17 نتيجة متوسطة مصدرها minimatch داخل شجرة ESLint/TypeScript. هي خارج حزم الإنتاج. اقتراح npm يتضمن تخفيضات غير متوافقة؛ لم يُستخدم `audit fix --force` ولم تُفرض minimatch 11 على مستهلكي الإصدار 3. تُتابع إصدارات الأدوات المتوافقة.
2. **مكافحة الرسائل الآلية:** إعداد Render الملتزم بالمستودع يجعل Turnstile معطلًا افتراضيًا. لم يُثبت وضع متغيرات الإنتاج الفعلي. راجع تفعيله ومفاتيحه والنطاقات. ضبط IP الفردي يحتاج ingress موثوقًا يكتب الترويسة وسر HMAC مشتركًا؛ لا تثق بـX-Forwarded-For عشوائي.
3. **الرفع والدعم:** تحقق تشغيليًا من فاحص الملفات والتخزين والبريد والنسخ الاحتياطية وتجربة الاستعادة. لم أغيّرها أو أفعّل رفعًا يتجاوز وضع الرفض الآمن.
4. **تحرير المحتوى:** بعض دراسات الحالة والمشاريع التوضيحية لها العنوان نفسه، وبعض محتوى التوظيف التجريبي باللغة الإنجليزية. لم تُعد كتابة سجلات CMS أو اختلاق وظائف أو عملاء. يُفضّل تمييز العناوين والوصف بحسب غرض الصفحة عند مراجعة المحتوى.
5. **Google Search Console:** إرسال sitemap ومراجعة التغطية وCore Web Vitals ونتائج البيانات المنظمة يحتاج الحساب المرتبط. لم تُدّع نتائج فهرسة أو ترتيب غير مقاسة.

## نتائج التحقق المحلي

- نجح بناء حزم المشروع وAPI والويب، وفحص أنواع API بما فيه الأدوات، وESLint لمجلدات apps وpackages وtests وscripts. صُححت ثلاث صيغ لاستيراد أنواع TypeScript في الاختبارات، دون تغيير سلوكها.
- **270 اختبار وحدة** ناجح، بما فيه اختبارات جديدة لإلغاء التدفقات المتوقفة وحفظ بايتات الرفع وحد الحجم، وتوافق مسارات الموارد واللغات وسياسات الفهرسة.
- مجموعة التصفح الكاملة: **105 حالات**. اجتازت 102 في الجولة الأولى؛ أُعيدت حالة نقرة الأتمتة الباردة واجتازت، وحُدّث اختبارا القائمة القديمان ليتجنبا احتساب بطاقة المعاينة كرابط خدمة إضافي ويحترما الخدمات المتقاعدة، ثم اجتازا الإعادة؛ أصبحت الحالات الثلاث ناجحة.
- فحص إضافي لـ**24 صفحة** (12 مسارًا بالعربية والإنجليزية) على 1440 و390 بكسل: canonical والوصف والعنوان وH1، عدم تجاوز عرض الشاشة، ومسح WCAG A/AA، دون أخطاء JavaScript.
- تحقق HTTP محلي من `no-store` و`X-Robots-Tag` على ردود API، و401 دون جلسة، و403 لطلبات الكتابة من Origin آخر.
- [سجل نتائج HTTP العامة قبل النشر](audits/2026-11-01-public-http.json).

## النشر والرجوع

يلزم نشر **الويب وAPI معًا** وتثبيت lockfile الجديد. لا يحتاج التحديث إلى ترحيل قاعدة البيانات. نقطة الرجوع: `checkpoint/pre-site-audit-20261101` عند `01708dc`؛ إعادة نشرها تعيد السلوك السابق والاعتماديات السابقة أيضًا.
