# لماذا TEVONIQ — قرار واضح وخطوة يمكن مراجعتها

30 أكتوبر 2026

## التصميم والمحتوى

صفحة عربية وإنجليزية خاصة بمسار `company/why-tevoniq`، بهوية ورقية دافئة وملف مشروع بطبقات وختم بصري، وأقسام داكنة للأمثلة التفاعلية. تتكامل مع «عن الشركة» وتشرح أسباب الاختيار بمخرجات عملية بدل ادعاءات عامة.

- مقدمة «قرار واضح. وخطوة يمكن مراجعتها.» ومسار من الاحتياج إلى التسليم.
- أربعة أسباب مرتبطة بمخرجات قابلة للمراجعة: خريطة احتياج، نطاق مكتوب، نسخة للتجربة، ملف تسليم.
- ثلاثة أمثلة للنطاق: موقع أعمال، نظام متابعة، أتمتة مهمة. لكل مثال سؤال أولي ومخرجات محتملة وحدود نراجعها قبل الالتزام ورابط إلى أمثلة الموقع الحالية. ليست عروض أسعار أو مشروعات عملاء.
- توضيح البداية المناسبة للمنشآت الصغيرة والمتوسطة، ودور أدوات الذكاء الاصطناعي مع المراجعة الهندسية.
- أسئلة عن السعر والمدة والتدرج والتواصل والتسليم، دون وعود زمنية أو مالية غير مثبتة.
- الاحتفاظ بجميع أقسام CMS المنشورة ومقدمة الصفحة والتغطية وسنة التأسيس إن وجدت، داخل سجل مبادئ قابل للتوسيع.

## التنفيذ

رسوم HTML وCSS وأيقونات النظام، دون صور ثقيلة أو مكتبة حركة إضافية. اختيار الأمثلة عبر radio أصلي؛ الأسئلة وحدود النطاق عبر details. تعمل هذه التفاعلات دون JavaScript وتدعم لوحة المفاتيح وتقليل الحركة.

الصفحة تظهر بعد تحقق النشر الحالي فقط، مع 404 لإلغاء النشر ورسالة تعذر عند فشل API. تبقى بيانات SEO من CMS. لم تُعدّل قاعدة البيانات أو النسخة التركية أو محتوى صفحات الشركة الأخرى أو ملفات التنقل. تبقى الخدمات المتقاعدة مخفية.

## التحقق

نجح بناء الويب وESLint و264 اختبار وحدة. فحص Chrome اختبر الأمثلة الثلاثة بالعربية والإنجليزية، لوحة المفاتيح، قوائم النطاق والأسئلة وسجل CMS، الروابط الداخلية والرابط القانوني canonical، الشاشات من 320 إلى 1440 بكسل، وإمكانية الوصول WCAG A/AA وتقليل الحركة. تحقق أيضًا من التفاعل دون JavaScript، بقاء «عن الشركة» والنسخة التركية، 404 عند إلغاء النشر، ورسالة تعذر API، وعدم إرسال أي نموذج تلقائيًا.

نجح 14 فحص متصفح للرئيسية والهيدر وسياسة الخدمات المتقاعدة. ضُبط عنوان الهيرو العربي بعد المراجعة البصرية، وأُعيد البناء وفحص رحلة الصفحة كاملة.
