## الحفاظ على المحتوى

يضيف الإصدار `2026-11-14-resource-library` الموارد الثلاثة مرة واحدة عبر نفس CMS، مع الحفاظ على المحتوى المطابق الموجود وتعديلات المالك ومحذوفاته. لا يستبدل سجل الاكتشاف الأصلي: يُظهر مكوّن خاص أسئلة إضافية وتنزيلًا عندما تكون صفحته منشورة. لا ينشئ نسخة مكررة منه، ولا يعيد إظهاره إذا أُرشف أو حُذف. لم تتغير التركية، وتظل المقالات السابقة كما هي.

صُححت فلترة RSS لاستخدام `articlePath`؛ مسارات الموارد العربية والإنجليزية هي `/insights/resources/` بينما تظل الموارد التركية على المسار السابق. يستخدم مخزون SEO ونظام sitemap القائمين.

## الاختبارات

- تحقق TypeScript وESLint واختبارات المحتوى وInsights ناجحة.
- اختبار PostgreSQL معزول ناجح لإضافة موارد الإصدار دون إعادة إنشاء محذوفات الإصدارات السابقة.
- أربعة موارد ظهرت في المعاينة، وكل صفحة وتنزيل أعاد HTTP 200، مع التحقق من توقيع PDF أو ZIP/XLSX.
- تنزيل متصفح فعلي دون تسجيل ناجح. الموارد الأربعة موجودة في RSS المحلية.
- لا تجاوز أفقي في القائمة عند 320 و390 و1440 بكسل وفي التفاصيل عند 320 و1440 بكسل. فحص axe داخل main لم يرصد مخالفات A/AA، ولا أخطاء JavaScript غير معالجة.
- رُسمت جميع صفحات PDF النهائية عبر Poppler وروجعت العربية والمسافات بصريًا.
- أنشئ Excel بأداة Artifact Tool، واختبر جمع 1000 و100 و0 و50 إلى 1150، ثم اختبر فراغ بند مطلوب، وأعيدت الخانات فارغة. لم يرصد مسح الأداة أخطاء صيغ. حُقق ZIP والصيغ الثلاث واتجاه الورقة RTL. لم تُجرَ جلسة تحقق داخل تطبيق Excel الأصلي.

## صيانة الملفات

مصدر بيانات القوالب والأسئلة في `apps/web/src/content/resource-library.ts`، وتعليمات الموارد في `content/resources-ar`. ملفات التنزيل ثابتة في `apps/web/public/downloads/resources`، ولا تحتاج خدمة ملفات أو بيانات عميل. يعيد `scripts/resources/build-pdfs.mjs` توليد PDFs باستخدام Node 24 وPlaywright؛ يجب تشغيل علامة بدء تأليف PDF الخاصة ببيئة الأدوات قبل إعادة التوليد ومراجعة صفحات الناتج. ملف المقارنة يتطلب إعادة التحقق من حساباته عند تعديله.

النشر على Render مطلوب لتطبيق الإصدار. رفع GitHub ليس إثباتًا لوجود الموارد على الإنتاج أو فهرستها.
