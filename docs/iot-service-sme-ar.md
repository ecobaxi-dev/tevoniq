# قسم الأنظمة المدمجة وإنترنت الأشياء

## الصفحة والمرجع

- المسار الحالي: `/ar/services/iot-solutions` و`/en/services/iot-solutions`.
- المرجع البصري والمعلوماتي: https://www.n-ix.com/iot-app-development-company/.
- التكوين المستفاد منه: هيرو مصور وشريط أقسام، وشبكة خدمات من ثلاثة أعمدة فوق خلفية متدرجة مع حواف برتقالية، وطبقات مسار البيانات، وبطاقات استخدام، وست مراحل تنفيذ وأسئلة شائعة.
- المحتوى مصاغ باسم TEVONIQ للمنشآت الصغيرة والمتوسطة، ويركز على قراءة وربط محدودين وتجربة توافق قبل التوسع. لا تُنسخ سنوات خبرة أو أعداد مشاريع أو عملاء أو شركاء أو اعتمادات أو نتائج من المرجع.
- التصوّر خلف شرط نشر الخدمة في CMS، مع الحفاظ على المحتوى التركي السابق. لا تعديل لقاعدة الإنتاج.

## المحتوى والروابط

ست خدمات: تقييم الاحتياج والتوافق، إثبات فكرة محدود، ربط أجهزة جاهزة، لوحات متابعة، قواعد تنبيه وربط إجراءات، والاختبار والتسليم. لكل خدمة مهام ومخرج واضح.

أربع طبقات: الجهاز والمستشعر، الاتصال والبوابة، التحقق والسجل، والمتابعة والإجراء. الأمثلة الثلاثة توضيحية ببيانات افتراضية: بيئة غرفة معدات، ومؤشر رطوبة نسبي، ومستوى خزان. لكل مثال نطاق وتجربة قبول وحدود ورابط تواصل مخصص.

مراحل التنفيذ الست تربط كل خطوة بمخرج قابل للمراجعة. يوضح المحتوى مسؤوليات المكونات والتركيب والطاقة والمعايرة والاتصال والتشغيل بدل افتراض تصنيع أو تركيب أو اعتماد شامل. لا تُستعاد الخدمات السحابية أو قوائم البيانات أو اختبارات الاختراق أو أي خدمات متقاعدة من المرجع.

تظهر خلاصة الصفحة المحدثة داخل دليل الخدمات أيضًا. روابط الصفحة كلها داخل الموقع. تهيئة التواصل تمرر معرف المثال المعتمد فقط، وتتجاهل القيم وملاحظات الزائر غير المعتمدة ولا ترسل رسالة تلقائيًا.

## المحاكي

- محاكاة محلية اختيارية، دون أجهزة أو إرسال أو أوامر تشغيل أو تخزين دائم.
- اختيار ثلاثة أمثلة، وتغيير القراءة وحد المراجعة وعمر القراءة وحالة الاتصال، ثم تقييم النتيجة بإجراء صريح.
- الحدود والقيم افتراضية؛ ليست توصيات لضبط جهاز أو ضمانًا لظروف بيئة فعلية.
- قيمة فوق الحد في مثال الحرارة، أو تحت الحد في المثالين النسبيين، تستدعي المراجعة. مساواة الحد حالة طبيعية في قاعدة المثال.
- القراءة بعمر يزيد على 15 دقيقة تُوسم بالمتقادمة في هذه التجربة، ولا يعاد تصنيفها كحالة حالية طبيعية أو متجاوزة للحد.
- انقطاع المصدر يسبق تقييم الحد ويعرض «لا قراءة جديدة»، دون قيمة أو مؤشر يوحيان بوجود قياس حديث.
- القيم الفارغة وغير المحدودة وخارج النطاق والعمر غير الصحيح تُرفض. مؤشر العرض محصور بين 0 و100.
- يحتفظ السجل بآخر خمس تجارب فقط؛ تغيير المثال أو إعادة الضبط يمسح السجل، وإعادة تحميل الصفحة تعيد الحالة الافتراضية.
- تبقى الخدمات والأمثلة والمراحل والأسئلة متاحة دون JavaScript، وتُخفى واجهة المحاكي حتى تفعيله بدل عرض أزرار لا تعمل.

## الأداء والتحقق

صورة الهيرو هي ملف IoT المحلي الخفيف المستخدم في قائمة التنقل، وتُعرض مباشرة دون معالجة أثناء الطلب. لا مكتبات رسوم بيانية إضافية أو مؤقتات اتصال أو طلبات أجهزة من المتصفح. تُستخدم أنماط الغلاف المشتركة مع ERP مع تنسيقات خاصة بقسم IoT.

التحقق يشمل بناء Next.js والأنواع وESLint وPrettier؛ واختبارات حدود المحاكي والانقطاع والتقادم والرسائل؛ وفحوص متصفح للنشر والحالات والسجل وإعادة الضبط والروابط وعدم الإرسال والإتاحة وغياب أخطاء المتصفح والعمل دون JavaScript والحفاظ على التركية ومقاسات 1440 و1024 و768 و390 و320؛ ثم فحص الدليل والأقسام والمعارض السابقة.
