# الاستشارات التقنية للمنشآت الصغيرة والمتوسطة

تطوير العرض الحالي في `/ar/services/it-consulting` و`/en/services/it-consulting` بمحتوى وأدوات أصلية تناسب اتجاه TEVONIQ، دون تغيير العرض التركي أو نقل ادعاءات عملاء أو فرق أو اعتمادات من مصادر خارجية.

## محتوى الصفحة

- عنوان «اختر الخطوة التقنية المناسبة لأعمالك» ومقدمة بصوت الشركة، مع رسم قرار خفيف مبني بعناصر HTML وCSS وأيقونات محلية، دون صور كبيرة أو مكتبات رسوم إضافية.
- أربع خدمات محددة: فهم الاحتياج والأولوية، مقارنة الخيارات، تحديد نطاق أولي، وتخطيط الربط والمتابعة.
- أداة «من أين أبدأ؟»، ومقارنة الخيارات، ومخرجات الاستشارة، وثلاث حالات افتراضية، وخطوات العمل، وروابط المعارض الأربعة، وأسئلة شائعة ودعوة للتواصل.
- المخرجات توصف ضمن نطاق متفق عليه: ملخص احتياج، نطاق أولي وحدود، وخيارات وخطة مراحل. لا وعود بتكلفة أو موعد أو نتائج رقمية دون مراجعة.

## منطق أداة البداية

خمسة أسئلة مغلقة عن النشاط والاحتياج والأداة الحالية والتكرار ووضوح المتطلبات؛ لا حقول اتصال ولا بيانات دخول. النتائج بقواعد معلنة وليست تقييمًا من نموذج ذكاء اصطناعي أو فحصًا فعليًا لبرامج العميل.

- المتطلبات غير الواضحة أو عدم معرفة إمكانات البرنامج: توضيح الاحتياج أولًا.
- وجود أداة مناسبة غير مستغلة: مراجعة الإمكانات الحالية قبل الاستبدال.
- تكرار عرضي مع الرغبة في الأتمتة: إجراء أبسط قبل إعداد ربط.
- التعريف بالنشاط: موقع ونموذج استفسار محدد.
- تنظيم الطلبات: مقارنة حل جاهز بنطاق متابعة محدود.
- خطوة متكررة بين أدوات قائمة ذات فجوات: مراجعة واجهات الربط ثم تجربة محدودة.
- عدم وجود مصدر أو اعتماد الربط على ملفات متفرقة: تنظيم البيانات أولًا.
- متابعة الأرقام مع مصدر مبدئي: لوحة تجيب عن سؤال محدد بعد التحقق من الحسابات.

لكل نتيجة سبب وثلاث خطوات أولى وما يُقترح تأجيله، مع معرض مناسب حيث ينطبق. يمكن تعديل الإجابات أو البدء من جديد أو تحميل ملخص نصي محلي. يوجد 900 تركيب صالح من الاختيارات.

## المقارنة والأمثلة

المقارنة تستعرض تحسين الموجود، واختيار حل جاهز، وربط الأدوات، وبناء نطاق مخصص. اختيار أولوية يفتح مسارًا للمراجعة، ولا يعطي درجة ملاءمة مزعومة أو قرارًا نهائيًا أو أسعارًا. يعرض كل خيار متى يستحق النظر وما نراجعه والمخرج والاعتماديات.

الحالات الثلاث افتراضية: متجر تتوزع استفساراته، ورشة تتشتت مواصفاتها، ومكتب خدمات يعيد نقل الطلبات. لكل حالة عرض للحاجة واتجاه البداية والنطاق والتأجيلات، مع تنزيل مثال نصي أصلي وربط بالمعرض المناسب. ليست قصص عملاء منفذة.

## التواصل والنشر

- تمرر الأداة اختيارات مغلقة فقط إلى التواصل عبر `consulting=guide`؛ يعاد التحقق منها على الخادم قبل صياغة الرسالة القابلة للتحرير. لا نصوص زائر حرة أو بيانات اتصال في هذه المعلمات.
- مسارات المقارنة والمثال والنطاق لها معرّفات معتمدة؛ المعلمات غير الصالحة تُتجاهل. تستمر اختيارات المعارض الأربعة السابقة.
- التنزيل محلي إلى TXT، ولا إرسال رسائل أو تنفيذ خارجي. لا اختيار برنامج تجاري أو اشتراك أو ربط فعلي آليًا.
- يستمر `getService` وحاجز نشر الخدمة قبل عرض التصميم الجديد؛ إزالة نشر الخدمة تبقي 404. لم تُستبدل بيانات CMS أو سياسة SEO أو صلاحيات الإدارة. توجد بيانات SEO احتياطية ملائمة للعرض الجديد، مع احترام سياسة SEO الحالية.
- أُزيل العرض الإضافي العام `VisualDiscovery` لهذه الخدمة بالعربية والإنجليزية لتجنب التكرار. التركية تبقى على القالب الحالي.

## التحقق ونقطة الرجوع

- نجح بناء الموقع وفحص ESLint وتنسيق الملفات.
- نجحت الاختبارات العامة الـ223، ومنها سبعة اختبارات لمنطق الاستشارة والتحقق من جميع تركيبات الإجابات الـ900 وروابط التواصل المعتمدة.
- نجحت اختبارات المتصفح الـ47 للصفحة الجديدة والخدمات والهيدر والمعارض الأربعة والصور، تحت حد heap للواجهة قدره 192 ميغابايت.

- اختُبر إلغاء النشر للغتين مع إبطال الذاكرة المؤقتة عبر وكيل CMS داخل fixture معزولة، وتأكد استمرار العرض التركي بالقالب السابق. لم يُكتب إلى CMS أو بيانات الإنتاج.
- فُحصت الصفحة بصريًا على الحاسوب والجوال. لا صور كبيرة أو مكتبات رسوم جديدة في هذه التوسعة.
