# حلول ERP وإدارة الأعمال للمنشآت الصغيرة والمتوسطة

## النطاق والمسار

- الصفحة الحالية: `/ar/services/erp-solutions` و`/en/services/erp-solutions`.
- المرجع البصري: https://www.n-ix.com/custom-erp-development-services/.
- أُخذ تكوين الهيرو مع مساحة لونية ورسم توضيحي، وشبكة الخدمات فوق خلفية متدرجة، وجدول المقارنة، وأربع مراحل التنفيذ. المحتوى مصاغ لاحتياجات TEVONIQ ونطاق التنفيذ المرحلي.
- يُحافظ على فحص نشر الخدمة في CMS قبل عرض التصميم، وعلى الصفحة التركية بمحتواها الحالي. لا تعديل لقاعدة البيانات أو إعدادات النشر الإنتاجية.

## أقسام الصفحة

1. هيرو يوضح ربط المبيعات والمخزون والتشغيل والعملاء في نظام واحد، برسم خفيف مبني بالكود.
2. ست فوائد عملية دون أرقام أو نتائج تسويقية غير مثبتة.
3. ست خدمات: تقييم الاحتياج، وحدات مخصصة، تهيئة سير العمل، الربط، تجهيز البيانات والاستيراد، ولوحات المتابعة والتسليم.
4. مستكشف وحدات: المبيعات والعملاء، طلبات الشراء، المخزون، التشغيل، الخدمة، والمشاريع والتقارير. لكل وحدة حقول ومخرج وحدود وروابط لنموذج قريب ولمناقشة الاحتياج.
5. مقارنة النظام الجاهز والتطوير المحدد عبر الملاءمة والنطاق والتكلفة والمدة والربط والمتابعة وملكية البيانات. تبقى بيانات الخيارين ظاهرة، ويمكن تحديد خيار لمناقشته.
6. ثلاثة أمثلة أصلية مرتبطة بنماذج إدارة العمل الحالية. ليست دراسات عملاء.
7. أربع مراحل تنفيذ بمخرجات محددة، وقائمة معلومات للبدء، وأسئلة شائعة.

## التفاعل والقيود

- تحميل ملخص الوحدة ملفًا نصيًا محليًا، مع وصف ومخرجات وحدود؛ لا يحتاج تقديم بيانات شخصية.
- التواصل يستقبل معرفات وحدات وخيارات معتمدة فقط، ويهيئ نصًا قابلًا للتعديل دون إرسال تلقائي.
- بيانات الربط والنماذج توضيحية، ولا توجد تكاملات فعلية أو إرسال خارجي من الصفحة.
- لم تُضف خدمات SAP أو RPA أو الاستشارات السحابية أو قوائم البيانات المحذوفة، ولا عملاء أو شركاء أو اعتمادات أو خبراء من المصدر.
- عرض الطلبات أو المبالغ لا يعني وجود محاسبة أو فوترة معتمدة. المتطلبات المالية والتنظيمية والأنظمة واسعة النطاق تُراجع وتُحدد بصورة منفصلة.
- الربط والاستيراد مرهونان بالصلاحيات والواجهات والبيانات واختبار عينة واعتماد الانتقال. لا وعود بربط غير محدود أو نتائج مضمونة.

## الإتاحة والأداء

- اتجاه عربي صحيح وتصميم متجاوب، وجدول محصور في منطقة قابلة للتمرير بلوحة المفاتيح على الجوال.
- اختيار الوحدات والخيارات بعناصر radio أصلية، والأسئلة الشائعة بعناصر details أصلية.
- عند تعطيل JavaScript يظهر محتوى المقارنة والخدمات وكل تفاصيل الوحدات عبر بديل قابل للفتح؛ تُخفى أدوات الاختيار والتنزيل التي تعتمد على JavaScript.
- الرسومات CSS/SVG ولا تتطلب صورًا كبيرة أو طلبات وسائط خارجية. إعداد تقليل الحركة يوقف حركة الرسم والانتقالات.

## التحقق ونقطة الرجوع

تشمل الفحوص بناء Next.js والتحقق من الأنواع وESLint، واختبارات ملخصات الوحدات وروابطها ورسائل التواصل، واختبارات متصفح للنشر والتفاعل والتنزيل والإتاحة والمقاسات 1440 و1024 و768 و390 و320 والعمل دون JavaScript والحفاظ على التركية، إضافة إلى اختبارات الصفحات السابقة.

نقطة الرجوع: `checkpoint/pre-erp-solutions-20261027` عند `245f13d` قبل التعديل. يمكن استعادة ملفات الصفحة من الوسم في تغيير جديد دون إرجاع أي عمل لاحق غير متعلق بها. النشر على Render يدوي بعد الرفع إلى `main`.
