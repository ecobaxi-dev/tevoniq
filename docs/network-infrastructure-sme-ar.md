# تطوير خدمة البنية التحتية للشبكات

## نطاق العرض

طُوّرت صفحة الخدمة القائمة `/ar/services/network-infrastructure` ونظيرتها الإنجليزية حول التصميم والمراجعة والإعداد والمراقبة والتوثيق للمنشآت الصغيرة والمتوسطة. بقيت التركية على القالب السابق. لا تعديل على بيانات الإنتاج أو حالة النشر في CMS.

العنوان «شبكة يعتمد عليها عملك»، مع رسمة أصلية متحركة ومحتوى شركة يشرح المخرجات وحدود التنفيذ. لا ادعاء فريق أو عملاء أو شراكات أو تغطية ميدانية دولية أو استجابة بشرية دائمة.

ستة محاور: التصميم والجرد، الشبكات السلكية واللاسلكية، الجدار الناري والربط، استمرارية الاتصال والاستعادة، المراقبة والتنبيهات، والإدارة والتوثيق. لكل محور مخرج ورابط تواصل مخصص. يُفصل شراء الأجهزة والتراخيص عن التصميم والإعداد والمعاينة والتمديدات والتركيب والمتابعة. التوريد والأعمال الميدانية تعتمد على بلد المشروع وترتيبات التنفيذ المؤكدة.

توضح الصفحة القيمة البرمجية: لوحة عربية لحالة الأجهزة والروابط والتنبيهات وسجل التغييرات وربط متابعة الأعطال بواجهات متاحة وصلاحيات معتمدة. لا تُقدّم اللوحة العامة للموقع على أنها نظام مراقبة فعلي جاهز أو متصل بشبكة عميل.

## مختبر الشبكة والسيناريوهات

ثلاثة أمثلة لمنشآت افتراضية: مكتب، متجر، وعدة مواقع. لكل دراسة مشكلة ونهج وأجهزة وبرمجيات وفحوص قبول وحدود. ليست أعمال عملاء أو مخططات تنفيذ معتمدة.

المختبر محاكاة محلية مبسطة. يختار الزائر مثالًا وعنصرًا من ستة عناصر لقراءة دوره: الإنترنت والبوابة والسويتش ونقاط الوصول وأجهزة العمل والضيوف. يمكن تبديل توافر الخط الأساسي والاحتياطي ومشاهدة حالة الاتصال الأساسي أو الاحتياطي أو غياب المسار. تجربة الضيف توضح سياسة الفصل في المثال ولا تفحص عزلًا حقيقيًا. لا وصول إلى أجهزة أو فتح اتصال أو تغيير إعدادات أو استدعاء API من المختبر.

## مرشد الاحتياج

أربع اختيارات: نوع الموقع، عدد الأجهزة التقريبي، أولوية التحسين، وطريقة التنفيذ المطلوبة. تنتج 54 تركيبة، بقواعد ثابتة تختار محاور المراجعة، دون تخمين طراز جهاز أو عدد نقاط وصول. يضاف التحقق من إمكان العمل الميداني عند طلبه، أو الوصول المصرح وخطة التراجع للمراجعة عن بُعد.

تُمسح النتيجة عند تغيير اختيار. يعيد زر البداية القيم الافتراضية. لا تخزين أو رفع ملفات أو طلب كلمات مرور أو إرسال تلقائي. يمكن نقل الملخص المعتمد إلى رسالة التواصل، ويظل الإرسال بيد الزائر.

## أمثلة الأجهزة والأدوات

تُعرض فئات قابلة للتقييم، وليست شراكات أو مخزونًا أو أسعارًا. الرسوم HTML وSVG وCSS أصلية وتوضح الفئات؛ ليست صور منتجات مصنعة أو شعاراتها.

- Cisco Catalyst 1200 / 1300: سويتشات للمكاتب والفروع، مع مراجعة المنافذ والطاقة والتوافق والطراز.

- Fortinet FortiGate: مثال لجدار الشبكة والربط والوصول، مع مراجعة الترخيص والأداء مع الخدمات المطلوبة.

## الدمج والتحقق

يخضع القالب الجديد لشرط نشر الخدمة نفسه. جُدّدت البيانات الوصفية وملخص دليل الخدمات ومعرفة المساعد، دون تغيير تعليماته أو مزوده أو معلومات مقر الشركة. لم تُستعد الخدمات المتقاعدة.

تُقبل سياقات `network=review` ومعرفات الخدمات والدراسات المعروفة ببادئتي `scope-` و`case-`. يقبل `network=guide` أربع قيم معتمدة فقط، ويرفض القيم الناقصة أو المتعددة أو المجهولة. حُفظت أولوية سياقات التواصل السابقة.

تعمل تفاصيل الأجهزة ودراسات السيناريوهات والخدمات والمراحل والأسئلة دون JavaScript. تظهر رسالة لاحتياج المختبر والمرشد إليه. يحترم رسم الهيرو تقليل الحركة. لا تنزيل صور أو نماذج أو مكتبات رسوم إضافية.

نقطة الرجوع `checkpoint/pre-network-infrastructure-20261030` تشير إلى `365c201` قبل التعديل. الرفع إلى `main` يجهّز النسخة للنشر اليدوي عبر Render.

نجح البناء و257 اختبار وحدة، بما فيها جميع تركيبات المرشد الـ54، وشروط المحاكاة، والتحقق من سياقات التواصل وحدود الدراسات. نجح فحص Chrome المخصص بالعربية والإنجليزية: حجب القالب عند إلغاء النشر، وست خدمات وست فئات أجهزة وثلاثة سيناريوهات، واختيار عناصر المخطط وحالات الاتصال وفصل الضيف، والمرشد وإعادة البداية وروابط التواصل ورفض القيم غير المعروفة، وبيانات FAQ منظمة. شمل الفحص عروض 320 و390 و768 و1024 و1440 وaxe A/AA وتقليل الحركة والمحتوى دون JavaScript وبقاء التركية. لم تظهر أخطاء متصفح أو طلبات تواصل تلقائية.

نجح 80 من 81 اختبار متصفح في الجولة الشاملة. كشف فحص قائمة التنقل وصفًا سابقًا بلون `#60768b` بلغ تباينه 4.49 مقابل خلفية التحويم `#f6faff`، دون الحد 4.5. عُدّل لون `.site-services-summary` إلى `#52697f` لتحسين الوضوح، وأُعيد البناء وفحص الهيدر والتنقل ودليل الخدمات.

نجحت إعادة فحوص الهيدر والتنقل ودليل الخدمات الأربعة عشر بعد تصحيح التباين، بما فيها الفحص المتعثر سابقًا. اجتازت بذلك الحالات المطلوبة الفحص بعد المعالجة، دون تغيير سلوك القائمة أو ألوان أزرارها.
