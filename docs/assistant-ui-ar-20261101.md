# تبسيط واجهة المساعد الذكي

1 نوفمبر 2026

## التغيير

- بداية هادئة بعنوان واحد ووصف قصير وثلاثة اقتراحات مختصرة. الضغط على الاقتراح يملأ السؤال للمراجعة ولا يرسله.
- رأس أبيض صغير، وزر محادثة جديدة يظهر بعد بدء المحادثة فقط، دون تكرار الأزرار أسفل النموذج.
- تختفي المقدمة والاقتراحات عند بدء المحادثة، لتبقى الرسائل محور النافذة.
- حقل كتابة يتمدد حتى حد محدد، وزر إرسال واحد. Enter للإرسال وShift+Enter لسطر جديد، مع احترام إدخال النص المركب IME.
- الموافقة على معالجة الرسائل عبر Cloudflare ظاهرة وصريحة وغير محددة افتراضيًا. لا تُحفظ عند إغلاق المساعد. تبقى تفاصيل المعالجة والبيانات الحساسة وحدود الإجابات وسياسة الخصوصية متاحة داخل قسم قابل للتوسيع.
- روابط الإجابات متاحة داخل «روابط قد تفيدك» بدل إظهار بطاقات متعددة مع كل رد. يستمر رفض الروابط الخارجية وغير الآمنة في ردود API.
- مؤشر انتظار خفيف، وعرض واضح للأخطاء، وتمرير الرسائل داخل مساحة مستقلة ليبقى حقل الكتابة ظاهرًا مع الردود الطويلة.
- نقل عرض الحوار إلى body عبر portal، حتى لا يختفي مع الشريط الجانبي عند تغيير مقاس الشاشة. الفتح من الوصول السريع في الجوال يبقى متاحًا.

لم تتغير API أو الموديل أو المعرفة أو الميزانية أو إعدادات Cloudflare. لا مكتبات إضافية ولا بيانات إنتاج معدلة. العربية والإنجليزية فقط كما في المساعد الحالي.

## التحقق

نجح بناء الويب وESLint وتنسيق الملفات واختبارات المساعد الأساسية العشرة. فحص Chrome بردود محاكية اختبر:

- العربية والإنجليزية، ومقاسات 1440×1000 و1024×768 و390×844 و320×568 و844×390، ومسح إمكانية الوصول WCAG A/AA.
- عدم الإرسال دون موافقة وعدم إرسال الاقتراح تلقائيًا، وفتح تفاصيل الخصوصية.
- Enter وShift+Enter، مؤشر الانتظار وتعطيل الإرسال أثناء الطلب، وعرض النص دون تفسير HTML.
- المحادثة متعددة الأدوار، وروابط داخلية قابلة للتوسيع، ورفض الروابط الخارجية والتنفيذية.
- إعادة البدء والأخطاء والردود الطويلة، وEscape وزر الإغلاق وإعادة التركيز إلى زر الفتح، وتجدد طلب الموافقة عند إعادة الفتح.
- فتح المساعد من قائمة الجوال وإلغاء طلب جارٍ دون ظهور جواب قديم بعد إعادة البدء.

اجتازت أيضًا اختبارات الهيدر الأربعة. عند إغلاق الحوار بعد الانتقال من مقاس الكمبيوتر إلى الجوال، ينتقل التركيز إلى زر الوصول السريع المرئي.

الاختبارات لا تستدعي الموديل الحقيقي ولا ترسل بيانات إلى Cloudflare. نقطة الرجوع: `checkpoint/pre-assistant-ui-20261101` عند `7dac4f4`. يكفي نشر الويب؛ لا ترحيل بيانات ولا تغيير لإعدادات API.
