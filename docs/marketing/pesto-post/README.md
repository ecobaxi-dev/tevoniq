# منشور بيستو لإدارة المطاعم

- [النسخة الطولية 1080 × 1350](pesto-portrait.png).
- [النسخة المربعة 1080 × 1080](pesto-square.png).
- [نص المنشور الجاهز للنسخ](caption-ar.md).
- [تحميل الحزمة](pesto-post.zip).

استُخدم شعار بيستو الأصلي، مع أخضر داكن وعاجي ولمسات خضراء وذهبية. الرسوم توضيحية لمسار العمل، وليست صورة لواجهة البرنامج. المعلومات مستندة إلى محتوى المنتج في `apps/web/src/content/pesto.ts`: أندرويد للنادل، ويندوز للخادم والبيانات، والدفع لدى الكاشير. لا يتضمن التصميم سعرًا أو وعد توفر تحميل أو تفعيل غير متحقق.

مصدر التصميم القابل لإعادة التوليد: `scripts/render-pesto-post.mjs`. ملفا HTML يحتويان الشعار والخط مضمنين للمعاينة المحلية. أُخرجت الصور وفُحصت في Chrome عبر Playwright، دون قص أو تداخل للتذييل. لم يُعدّل الموقع، ولا يحتاج استخدام الصور إلى نشر تحديثه.
