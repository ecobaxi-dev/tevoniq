# قالب تأكيد الاشتراك في النشرة

قالب HTML بالعربية والإنجليزية مع نسخة نصية بديلة، يُستخدم من `GenericNewsletterProvider` عبر SMTP أو Resend. المحتوى التركي السابق محفوظ دون تغيير. يتضمن زر تأكيد، صلاحية 48 ساعة، توضيح أن الاشتراك لم يتفعّل بعد، رابطًا بديلًا وإلغاء الطلب وسياسة الخصوصية. لا صور خارجية ولا تتبع فتح البريد.

- [معاينة عربية](ar-preview.png)
- [معاينة إنجليزية](en-preview.png)

المعاينات مولدة محليًا ببيانات ورموز وهمية، وليست رسائل مرسلة. فُحص العرض في Chromium دون JavaScript بعرض 320 و390 و800 بكسل دون تجاوز أفقي؛ قد تختلف التفاصيل البصرية في Gmail وOutlook. الرسائل السابقة لا تتغير بعد النشر.

التحقق: بناء API وESLint ناجحان، و23 اختبارًا للنشرة والقالب والتواصل ناجحة. في 13 نوفمبر 2026 رفض الموقع المنشور اشتراكًا بلا رمز Turnstile بحالة 400، واشتراكًا برمز غير صالح بحالة 400. لم يُرسل بريد فعلي من هذه الاختبارات. وضع `interaction-only` يسمح بالتحقق الصامت؛ لا يلزم ظهور مربع في كل اشتراك.
