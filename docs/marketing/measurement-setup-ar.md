# تفعيل القياس ومراجعة الظهور

## حالة التنفيذ

أُضيفت أحداث قياس داخل الموقع، وتعمل عند وجود إعداد GA4 أو GTM صالح وموافقة الزائر حسب سياسة الموافقة الحالية. لم يُنشأ حساب Google ولم تُعدّل حسابات أو حاويات أو إعدادات الإنتاج. تتطلب الأرقام الفعلية نشر Web وربط الحساب الذي يملكه صاحب المشروع. الاختبارات تستخدم معرّفًا وهميًا وتمنع طلبات Google.

## GA4 — المسار الأبسط

- استخدم حساب الشركة وأنشئ/اختر خاصية GA4 وتدفق Web لعنوان الموقع الحقيقي.
- في إعدادات الموقع داخل CMS، أدخل Measurement ID بصيغة `G-...` في إعداد Google Analytics، ثم احفظ. هذا المعرّف عام وليس API secret؛ لا نحتاج كلمة مرور حساب Google.
- استخدم GA4 وحده بدايةً إن لم تكن هناك حاجة لحاوية GTM. إذا كانت الحاوية قائمة، راجع علاماتها قبل تفعيل الاثنين معًا حتى لا تجمع الزيارة أو الإرسال مرتين.
- اختبر من نافذة جديدة: قبل الموافقة لا يفترض تحميل GA عندما تكون موافقة التحليل مطلوبة؛ بعد قبول التحليل نفّذ رحلة نموذج ببيانات اختبار، وراجع Realtime ثم التقارير بعد معالجة البيانات.
- عيّن `generate_lead` حدثًا رئيسيًا إذا لم يكن مُعدًا بالفعل. اعتبره استلام استفسار فقط، وليس عميلًا مؤهلًا أو بيعًا.
- راجع إعداد Enhanced Measurement: عطّل القياس التلقائي لتفاعلات النماذج إن سبب تكرار `form_start`، وعطّل قياس تغيرات history التلقائي عند استخدام page_view اليدوي. أحداث هذه الحزمة لا ترسل محتوى الحقول أو query strings أو عناوين صفحات يدخلها الزائر. إعدادات حاوية خارجية قد تجمع بيانات إضافية ويجب مراجعتها بصورة مستقلة.

## الأحداث

| الحدث             | متى يحدث؟                                                                |
| ----------------- | ------------------------------------------------------------------------ |
| `page_view`       | عرض صفحة مع السماح بالقياس؛ لا يُعاد إرسال الزيارات السابقة قبل الموافقة |
| `service_view`    | زيارة قسم الخدمات أو صفحة خدمة                                           |
| `demo_open`       | الضغط على رابط إلى مجموعات النماذج أو نموذج                              |
| `demo_video_play` | تشغيل عرض قصير؛ تكرار التشغيل قد يولد حدثًا آخر                          |
| `contact_open`    | الضغط على رابط التواصل أو طلب عرض سعر                                    |
| `form_start`      | أول إدخال في نموذج التواصل/السعر خلال عرض الصفحة المسموح بقياسه          |
| `generate_lead`   | رد ناجح من API يتضمن مرجع الطلب؛ أخطاء الإرسال لا تولده                  |

تتضمن المعاملات نوع الصفحة واللغة والمسار المنقّح، ونوع النموذج أو رمز العرض عند الحاجة. لا تُرسل الأسماء أو البريد أو الهاتف أو الرسالة أو مرجع الطلب. مسارات مجهولة أو slugs غير معروفة تُختصر إلى فئة عامة. لا نستخدم معرف تتبع بديلًا عند رفض الموافقة ولا نعيد إرسال التفاعلات السابقة للموافقة.

## GTM إذا اختير بدل GA4 المباشر

عند تفعيل GTM وحده، تصل الأحداث إلى dataLayer باسم `tevoniq_page_view` و`tevoniq_generate_lead` وهكذا، مع بقية الأسماء السابقة مسبوقة بـ`tevoniq_`. جهز Custom Event triggers وGA4 Event tags لتحويلها إلى الأسماء القياسية، ثم اختبر في Preview وانشر الحاوية. يلزم قبول التحليل والتسويق لتشغيل GTM وفق السياسة الموجودة لأنه يستطيع تشغيل النوعين. إن كان GA4 المباشر وGTM مفعّلين، يرسل هذا التحديث أحداث الرحلة عبر GA4 المباشر فقط؛ لا تجهز علامات أخرى تكررها.

## روابط الحملات

القياس اليدوي يقبل أسماء محددة فقط حتى لا تمر بيانات شخصية عبر UTM:

- source: `site`, `linkedin`, `instagram`, `youtube`, `referral`.
- medium: `social`, `video`, `sector`, `guide`, `partner`.
- campaign: `month1-website`, `month1-requests`, `month1-automation`, `month1-dashboard` أو رموز صفحتي القطاعين والمقالتين.

مثال: `https://www.tevoniq.com/ar/showroom?utm_source=linkedin&utm_medium=video&utm_campaign=month1-website`.

هذه معاملات لقياس الزيارة ذات الوسم، وليست نظام إحالة متعدد الزيارات؛ لا يخزن هذا التحديث حملة دائمة عند رفض التخزين، ولا يختلق نسبة تحويل لمن لم يوافق على التحليل. قد تختلف أعداد GA عن الطلبات الفعلية في CMS بسبب الرفض والحجب.

## Search Console

أضف خاصية للموقع في حساب الشركة. تحقق من الملكية عبر الطريقة التي يعرضها Google؛ خيار Domain يحتاج سجل DNS لدى الجهة المسؤولة عن النطاق، ولا نغيّر DNS دون التحقق من السجل المطلوب. قدّم `https://www.tevoniq.com/sitemap.xml` ثم استخدم URL Inspection لصفحات القطاعين والدليلين والعروض. راجع اختيار canonical وحالة الفهرسة أسبوعيًا؛ طلب الفهرسة لا يضمن قبولها أو موعدها أو ترتيبها.
