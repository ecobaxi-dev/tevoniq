# ستة منشورات فيسبوك بهوية TEVONIQ

التصاميم مستوحاة من صفحة «لماذا TEVONIQ»: الخلفية العاجية `#faf8f1`، الأخضر الداكن `#17333b` و`#173b36`، اللون النحاسي `#a34524`، وملف المشروع والبطاقات الورقية. استُخدم خط Cairo نفسه وشعار الشركة الموجود بالمشروع.

## المعاينة والتنزيل

- افتح [المعرض](index.html) لمشاهدة التصاميم وفتح نص كل منشور.
- [تحميل الحزمة كاملة](facebook-posts.zip).
- [معاينة التصاميم الستة معًا](all-posts-preview.png).
- [نصوص المنشورات والروابط](captions-ar.md).

كل صورة PNG بمقاس **1080 × 1350 بكسل** ونسبة 4:5. النص والصورة متكاملان: ارفع الصورة ثم انسخ النص والرابط الخاصين بها. الروابط في التعليقات النصية قابلة للنقر، أما عنوان الموقع داخل الصورة فهو جزء من التصميم.

| [03-workflow-automation.png](03-workflow-automation.png) | الأتمتة            |

الرسومات مفاهيم توضيحية أصلية، وليست مشروعات عملاء أو إحصاءات نتائج فعلية. مخطط لوحة المعلومات موسوم بأنه توضيحي. تستخدم النصوص صوت الشركة دون ادعاء موظفين أو شراكات أو نتائج.

مصدر النصوص: `scripts/lib/facebook-posts.mjs`. مولّد المعرض المستقل: `scripts/render-facebook-kit.mjs`. يحتوي HTML على الخط والشعار مضمنين لعرض المعاينة دون خدمات خارجية. يتضمن الملف `FONT-LICENSE.txt` ترخيص خط Cairo. توليد الصور وفحصها تم بواسطة Chrome وPlaywright بدقة 1:1؛ لا يلزم تعديل الموقع أو إعادة نشره لاستخدام الحزمة.
