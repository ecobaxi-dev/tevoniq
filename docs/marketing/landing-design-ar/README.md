# تحسين تصميم صفحة الهبوط العربية

المسار: `/ar/start`. يستخدم التصميم الشعار الأفقي الأصلي عبر `BrandLogo`، ولوحة ألوان كحلية وسماوية مع خلفيات فاتحة. يشمل التحسين القسم الافتتاحي وبطاقات الخدمات وطريقة العمل ونموذج التواصل والأسئلة الشائعة. التنسيق الإضافي محصور في `.campaign-ar`.

- [معاينة الكمبيوتر](desktop.png)
- [معاينة الجوال](mobile.png)
- [نتائج الفحص](checks.json)

اختبارات Chromium محلية ببيانات API تجريبية: الشعار محمّل، لا تجاوز أفقي عند 320 و390 و768 و1440 بكسل، ولا مخالفات axe ضمن main على مستوى WCAG A/AA المفحوص. نجح النموذج باستجابة قبول وهمية مع حفظ UTM، ولم تُرسل بيانات إلى الإنتاج. التحقق من عدم تطبيق التنسيق العربي على الصفحة الإنجليزية ناجح. TypeScript وتنسيق الملفات ناجحان. هذه المعاينات لا تثبت نشر التصميم على Render.
