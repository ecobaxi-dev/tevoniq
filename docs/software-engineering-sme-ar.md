# هندسة المنتجات البرمجية للمنشآت الصغيرة والمتوسطة

## المسار والمرجع

- الصفحة الحالية: `/ar/services/software-product-engineering` و`/en/services/software-product-engineering`.
- المرجع: https://www.n-ix.com/software-engineering-services/.
- التكوين المستفاد منه: هيرو بصري، قائمة خدمات جانبية وتفاصيلها، مراحل قابلة للاستكشاف، بطاقات دراسات حالات، وقسم جودة بخلفية متدرجة.
- النصوص والأمثلة مصاغة لاحتياجات TEVONIQ ونطاق مرحلي؛ لا نسب إنتاجية أو سنوات خبرة أو أسماء عملاء أو موظفين أو شهادات من المرجع. لا يُستخدم اسم إطار المصدر أو وعوده.
- العرض خلف شرط نشر الخدمة الحالي في CMS، مع إبقاء المسار والمحتوى التركي الحالي دون تطوير جديد.

## أقسام الصفحة

1. هيرو برسم برمجي خفيف يوضح المتطلبات والتصميم والبناء والاختبار.
2. أربع ركائز: نطاق واضح، تجربة قابلة للمراجعة، اختبار قبل الإطلاق، وتسليم منظم.
3. مستكشف خدمات: تحليل النطاق، تجربة المستخدم، المواقع والأنظمة، الربط، تحسين برنامج قائم، والاختبار والتسليم.
4. مراحل: نحدد، نجرّب، نبني ونختبر، نسلّم ونحسّن. لكل مرحلة مخرج وشرط قرار قبل الانتقال.
5. ثلاث دراسات سيناريوهات أصلية توضيحية: طلبات صيانة، مخزون نشاط تجاري، ومتابعة استفسارات موقع. كل دراسة تشمل المشكلة والنطاق ومعايير قبول والربط الممكن وما يؤجل والمخرج المقترح ورابط نموذج يمكن تجربته.
6. جودة التنفيذ عبر المتطلبات والاختبار والتشغيل، مع شرح دور المساعدة بالذكاء الاصطناعي والمراجعة البشرية.
7. معلومات البدء والتواصل والأسئلة الشائعة.

## ضوابط الأمثلة والتواصل

- الدراسات موسومة بأنها توضيحية، وليست أعمال عملاء أو نتائج فعلية. لا توجد شهادات منسوبة لعملاء أو نسب تحسن مفترضة.
- النماذج مرتبطة بالمعارض والمحاكيات الحالية داخل الموقع؛ لا إرسال فعلي أو تكامل إنتاجي من الصفحة.
- رسائل التواصل تستخدم قائمة مغلقة من أنواع السياق ومعرفاته: خدمة أو مرحلة أو دراسة سيناريو. لا تُنسخ بيانات زائر عشوائية إلى النص أو الرابط، ولا إرسال تلقائي.
- لم تُستعد الخدمات المحذوفة، ومنها توسعة الفرق وSAP وRPA والاختبارات الأمنية والقوائم السحابية والبيانات والألعاب.

## التنفيذ والتحقق

يستخدم المكوّن أنماط الغلاف والتنسيق والأزرار المشتركة حاليًا مع صفحة ERP (`erp-service.css`)، ويضيف تنسيقات محددة داخل `se-service` دون تغيير تنسيقات ERP. تُفحص الصفحتان مع بقية الصفحات لمنع أي أثر متبادل.

المحتوى المعتمد على الاختيار يظهر عبر عناصر radio أصلية. يُعرض محتوى الخدمات والمراحل كاملًا من الخادم، وتظهر أدوات الاختيار وتُفعّل تصفية التفاصيل بعد تهيئة JavaScript فقط. عند تعطيله تبقى كل التفاصيل ظاهرة، وتبقى الدراسات والأسئلة قابلة للفتح بعناصر HTML أصلية. إعداد تقليل الحركة يوقف حركة الرسم.

الفحوص: بناء Next.js والتحقق من الأنواع وESLint وPrettier، واختبارات وحدات للروابط والمعرفات ورسائل التواصل، واختبارات متصفح للنشر والتفاعل والدراسات والإتاحة والمقاسات 1440 و1024 و768 و390 و320، والعربية والإنجليزية والتركية المحفوظة والعمل دون JavaScript، ثم فحص صفحات ERP والأتمتة والاستشارات والمعارض والهيدر والبداية والخدمات المحذوفة.
