# أتمتة ضمان الجودة للمنشآت الصغيرة والمتوسطة

## العرض والمحتوى

طُوّر القسم الحالي `/ar/services/qa-automation` ونظيره الإنجليزي بالاستفادة من توزيع صفحة <https://www.n-ix.com/qa-automation-services/>: هيرو أبيض مع خلفية برتقالية للرسمة، فوائد مختصرة، بطاقات بيضاء على تدرج بنفسجي، مراحل مرقمة ودراسات سيناريوهات وأسئلة شائعة.

العنوان العربي «اختبر اليوم، وأطلق بثقة». المحتوى والرسوم أصلية ومناسبة لنطاق TEVONIQ. لا تُنسب دراسات عملاء المرجع أو نتائجه أو خبراته إلى الشركة. لا ادعاءات فرق أو عملاء أو اعتمادات أو نسب تسريع. لا روابط أو صور أو فيديوهات خارجية داخل القسم. لم تُستعد الخدمات المتقاعدة.

ستة محاور: مسارات المستخدم، واجهات الربط، فحص التحديثات، العربية والجوال والمتصفحات، تشغيل الاختبارات من المستودع، والمراجعة اليدوية المكمّلة. لكل محور مخرج ورابط تواصل يحمل سياقه. تُشرح جدوى الأتمتة وحدودها دون ضمان غياب الأخطاء.

أربع مراحل باختيارات تعمل دون JavaScript: تحديد الأولويات، بناء الاختبارات، التشغيل والتوثيق، والتسليم والصيانة. تعرض كل مرحلة العمل والمخرجات والمدخلات المطلوبة. تظهر كل التفاصيل في متصفحات لا تدعم `:has`.

## المختبر ودراسات السيناريوهات

مختبر تفاعلي صغير ينفذ قواعد برمجية تجريبية داخل المتصفح عند الضغط على زر التشغيل فقط. يختار الزائر السيناريو ونسخة قبل التصحيح أو بعده، ويشاهد المتوقع والفعلي وحالة كل اختبار. تتغير النتائج بحسب التنفيذ الحقيقي للقواعد، دون مؤقتات أو شبكة أو بيانات إنتاج. تُمسح النتائج عند تبديل الإعدادات، وتُعلن حالة التشغيل لتقنيات المساعدة.

- سلة متجر: الحساب ورفض الكمية صفر أو كسرية أو فوق الحد، دون دفع أو ضرائب أو مخزون.
- حجز: قبول وقت متاح ورفض المشغول والفارغ، دون ادعاء اختبار التزامن أو حفظ حجز.
- صلاحيات: قبول المشرف ورفض الموظف والدور غير المعروف. فحص وظيفي محلي، ولا يمثل تدقيقًا أمنيًا أو اختبار اختراق.

الدراسات لمنشآت افتراضية، وتتضمن المشكلة ونهج الفحص والنطاق ومعيار التقييم والحدود. ترتبط بنماذج المتجر والمواعيد والصيانة القائمة، دون الإيحاء بأن المختبر فحص تلك النماذج فعليًا. بقية المحتوى يعمل دون JavaScript، مع رسالة تشرح احتياج المختبر إليه.

## التكامل والنشر

يستخدم القسم شرط نشر الخدمة الحالي، وتبقى التركية على القالب السابق. جُدّدت ملخصات الدليل والبيانات الوصفية ومعرفة مساعد الموقع تحت شرط النشر نفسه. لم تتغير تعليمات المساعد المتعلقة بالمقر أو أسلوب المحادثة.

تُقبل سياقات `qa` المعتمدة فقط: `review`، ومعرفات المحاور الستة، والدراسات الثلاثة ببادئة `case-`. يُجهّز رابط التواصل رسالة ولا يرسلها تلقائيًا. حوفظ على أولوية السياقات السابقة.

الرسوم من HTML وSVG وCSS، دون صور جديدة أو مكتبات رسوم أو طلبات API إضافية. يحترم الرسم إعداد تقليل الحركة. لا تعديل على قاعدة البيانات أو إعدادات الإنتاج أو حالة النشر في CMS.

نقطة الرجوع `checkpoint/pre-qa-automation-20261029` تشير إلى `6c53bdb` قبل التعديل. التحديث إلى `main` يجهّز النسخة للنشر اليدوي عبر Render.

## التحقق

نجح البناء وفحص ESLint و251 اختبار وحدة، بما فيها اختبار حدود قواعد المختبر وسياقات التواصل وروابط النماذج. نجح فحص Chrome المخصص بالعربية والإنجليزية: حجب الخدمة عند إلغاء نشرها، والمحاور الستة والمراحل الأربع والدراسات الثلاثة، وتشغيل السيناريوهات قبل التصحيح وبعده ومسح النتائج، وروابط النماذج والتواصل ورفض السياق المجهول، وستة أسئلة FAQ منظمة.

اجتازت الصفحة عروض 320 و390 و768 و1024 و1440، وعنوانًا بسطر واحد على الكمبيوتر، وفحص axe A/AA، وتقليل الحركة. اختُبرت المراحل والدراسات والمحتوى دون JavaScript وبقاء التركية على القالب السابق. لم تظهر أخطاء متصفح أو طلبات تواصل تلقائية.

نجحت اختبارات التوافق الـ81 في Chrome، بما فيها دليل الخدمات والتنقل والرئيسية وبقية صفحات الخدمات ومجموعات النماذج والخدمات المتقاعدة. حُدّثت بيانات دليل الخدمات في بيئة الاختبار لتضم أتمتة ضمان الجودة والعدد المتوقع لبطاقاتها.
