# صفحة عن الشركة — استوديو الفكرة

30 أكتوبر 2026

## الفكرة والتطبيق

تصميم أصلي بطابع لوحة هندسية: خلفية داكنة بشبكة دقيقة، وألوان ورقية وخضراء هادئة، ومسار من فهم الاحتياج إلى التسليم. لا ندّعي إثبات عدم وجود تصميم مشابه في أي موقع آخر.

تتضمن الصفحة:

- مقدمة «تبدأ من عملك. وتتشكّل حولك.» وصياغة تناسب المنشآت الصغيرة والمتوسطة.
- لوحة تفاعلية بأربع مراحل: نفهم، نرسم، نبني، نسلّم. يتغير وصف المرحلة ومدخلاتها ومخرجاتها ورسمها، عبر عناصر radio أصلية وCSS دون مكوّن JavaScript إضافي.
- وجهة نظر الشركة، ومبادئ قابلة للتوسيع، وأربع بدايات ترتبط بالمواقع وأنظمة العمل والأتمتة والذكاء الاصطناعي الموجودة.
- هوية مقر إسطنبول والأساس الهندسي وفق إفادات المالك. لا أرقام أداء أو عملاء أو موظفين أو اعتمادات مستحدثة.
- سجل قابل للتوسيع يحفظ مقدمة الشركة وأقسامها وسنة التأسيس والتغطية الجغرافية عند وجودها في المحتوى المنشور.
- دعوة إلى مناقشة الاحتياج وتجربة النماذج.

## حدود التعديل

يطبق على صفحة `company/about` بالعربية والإنجليزية فقط. يبقى المحتوى التركي وعرض صفحات الشركة الأخرى كما هما. لا تغيير في قاعدة البيانات أو حالة النشر. يحتفظ المسار بتحقق النشر: 404 عند إلغاء النشر، ورسالة تعذر عند فشل مصدر المحتوى. بيانات العنوان والوصف لمحركات البحث تبقى من لوحة المحتوى.

الرسوم HTML وCSS وأيقونات النظام، دون صور ثقيلة أو مكتبات حركة جديدة. تعمل المراحل والقوائم دون JavaScript وتدعم لوحة المفاتيح، مع إيقاف الحركة عند تفضيل تقليلها.

## التحقق والرجوع

نجح بناء الويب وفحص ESLint و264 اختبار وحدة. فحص Chrome اختبر العربية والإنجليزية من 320 إلى 1440 بكسل، المراحل الأربع، لوحة المفاتيح، فتح المبادئ وسجل الشركة، الروابط المحلية، إمكانية الوصول WCAG A/AA، وتقليل الحركة. تحقق أيضًا من عدم النشر وتعذر API والتصفح دون JavaScript وبقاء النسخة التركية.

نجح أيضًا 19 فحصًا للرئيسية والهيدر والقوائم والخدمات المخفية. احتاج فحص القوائم البصرية إلى إعادة بسبب إغلاق قائمة Radix أثناء المسح الآلي، ثم اجتاز دون تغيير ملفات التنقل.
