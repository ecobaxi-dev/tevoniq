# مساعد TEVONIQ مع Cloudflare Qwen

اعتمد المستخدم تجربة Qwen عبر Cloudflare في 29 أكتوبر 2026. الربط والواجهة مكتملان برمجيًا؛ التفعيل الحقيقي يحتاج بيانات حساب Cloudflare واختبارًا فعليًا للنموذج. لا توجد هذه البيانات في الإعدادات المحلية التي فُحصت، ولا توكن ضمن الكود أو المستودع.

## التفعيل في Render

ابدأ بالتفعيل في البيئة التجريبية أو محليًا لاختبار الأسئلة العربية قبل إظهاره للزوار.

1. افتح حساب Cloudflare على الخطة المجانية، ثم Workers AI → Use REST API. لا يحتاج هذا الربط نقل النطاق أو الاستضافة.
2. انسخ Account ID، وأنشئ Workers AI API Token من القالب الرسمي. توضح وثائق Cloudflare أن التوكن يحتاج `Workers AI - Read` و`Workers AI - Edit`.
3. في Environment لخدمة Render التي تشغّل الويب، أضف:

```dotenv
SITE_ASSISTANT_ENABLED=true
CLOUDFLARE_ACCOUNT_ID=<معرّف الحساب: 32 محرفًا سداسيًا>
CLOUDFLARE_AI_TOKEN=<توكن Workers AI>
```

يجب أن يبقى `SITE_URL` الحالي مطابقًا لأصل الموقع الفعلي، بما فيه `www` إن كان مستخدمًا. ضع السر في Render فقط، ولا ترسله في المحادثة أو تضفه إلى Git أو متغير `NEXT_PUBLIC_`.

4. أعد تشغيل/نشر خدمة Render. يظهر زر «المساعد الذكي» في الشريط الجانبي، وعلى الهاتف ضمن الوصول السريع.
5. ابدأ بأسئلة الاختبار أدناه وتأكد من ظهور إجابات حقيقية في حسابك ومراقبة الحصة. عند إخفاق التوكن أو نفاد الحصة تظهر رسالة تعذر الإجابة وروابط التواصل، ولا تُعرض إجابات مصطنعة.

للتعطيل: `SITE_ASSISTANT_ENABLED=false` ثم إعادة التشغيل. يبقى المساعد مخفيًا أصلًا إذا كان العلم غير مفعّل أو بيانات الحساب ناقصة/صياغتها غير صالحة. الإعدادات تقرأ على الخادم أثناء التشغيل، وليست أسرارًا مضمنة وقت بناء JavaScript.

## الربط

- النموذج ثابت: `@cf/qwen/qwen3-30b-a3b-fp8`، والمزود الوحيد هو Cloudflare Workers AI REST API. لا تغيير تلقائي إلى مزود آخر أو نموذج مدفوع.
- واجهة محادثة عربية/إنجليزية تُحمَّل ديناميكيًا عند فتحها. لا طلب AI عند فتح الصفحة أو اقتراح السؤال، ولا تنزيل نموذج على جهاز الزائر.
- POST إلى `/api/assistant` من أصل الموقع نفسه، مع جسم محدود بـ20,000 بايت، وسؤال أقصاه 800 محرف وست رسائل سياق سابقة أقصى كل منها 900 محرف. لا يقبل الخادم رسائل system أو اختيار النموذج من العميل.
- عند التفعيل تتضمن صفحة الخصوصية العربية/الإنجليزية وصف معالجة رسائل المساعد.
- يلزم تأشير موافقة معالجة الرسائل عبر Cloudflare قبل الإرسال. توجد إحالة لسياسة الخصوصية وتنبيه عن البيانات الحساسة وعن احتمال أخطاء الذكاء الاصطناعي.
- حد خرج 700 token، ومهلة 20 ثانية لاستدعاء المزود. تُقرأ استجابته بحجم محدود، وتزال كتل التفكير المكتملة وتُرفض غير المكتملة أو الاستجابة غير الصالحة.
- النص يعرض كنص فقط؛ لا HTML أو أدوات أو تنفيذ تعليمات. روابط الصفحات يولدها الخادم من قائمة المعرفة، ولا تؤخذ من روابط يقترحها النموذج.
- لا حفظ للمحادثة في قاعدة بيانات أو localStorage أو سجلات الطلبات. تحتفظ الواجهة بحالة مؤقتة أثناء فتحها، وتعيد «محادثة جديدة» تهيئتها. يؤدي الإغلاق أو تغيّر الصفحة إلى إزالة الجلسة وإلغاء انتظار المتصفح.

## المعرفة والنشر

المعرفة الأولية تستخدم محتوى الخدمات الأربع في الصفحة الرئيسية ووصف بيستو والمحامون وقواعد العمل المعتمدة. تضيف الأوصاف الحديثة للاستشارات والأتمتة وERP وهندسة البرمجيات وإنترنت الأشياء فقط عندما تُرجع واجهة الخدمة منشورًا عامًا في اللغة الحالية. تستخدم فحص النشر والكاش نفسه المستخدم في الصفحة، مع استبعاد الخدمات الملغاة.

يختار استرجاع نصي خفيف أربع صفحات ذات صلة، ويضيف حدود الشركة في كل طلب. يُمنع اختراع فريق أو عملاء أو اعتمادات أو نتائج أو أسعار ومواعيد أو جاهزية تحميل. النماذج توضيحية، والمعلومة الناقصة تُحال للتواصل. لا تدريب أو قاعدة متجهات مستقلة في هذه المرحلة، ولا وصول إلى ملفات التدقيق الداخلية أو بيانات CMS الخاصة.

المحتوى شركة/منتجات/خدمات منشورة فقط، وليس كل صفحة في الموقع بعد. تُوسّع المعرفة لاحقًا عند الحاجة، وتُراجع دقة الربط والصياغة بالعربية قبل الاعتماد العام.

## الحدود والتكلفة

حماية أولية لكل عملية خادم: طلب واحد قيد المعالجة، و6 طلبات/دقيقة، و30/ساعة، و100/يوم لجميع الزوار معًا. تحتسب المحاولات الفاشلة أيضًا. لا يعتمد العداد على عناوين IP أو cookies؛ لا تُجمع معرّفات زوار لهذا الغرض.

هذه حدود ذاكرة لنسخة Render الواحدة، وتُعاد عند إعادة التشغيل ولا تتشارك بين النسخ. ليست حصة مالية ملزمة أو ضمانًا لعدم الفوترة. أبق حساب Cloudflare على الخطة المجانية للوقوف عند حصتها؛ إذا كان حسابك مدفوعًا فقد تسمح خطة المزود بفوترة التجاوز. قبل توسيع الموقع لنسخ متعددة نحتاج عدادًا مشتركًا/حماية على الحافة. رسالة الحد المؤقت تحول المستخدم للتواصل بدل تعطل بقية الموقع.

## نتائج التحقق قبل التفعيل

نجح بناء الويب و244 اختبار وحدات، إضافة إلى فحص Chrome بالعربية والإنجليزية من الواجهة إلى مسار API ثم إلى نقل Cloudflare محاكى محليًا. شمل الفحص الموافقة قبل الإرسال، والسياق المحدود، وعرض النص غير الموثوق دون HTML، وروابط المعرفة وعدم تضمين خدمة أُلغي نشرها، والخصوصية، والمحادثة الجديدة، والإغلاق واستعادة التركيز، و451/400 بكسل ارتفاعًا و390/320 بكسل عرضًا، وaxe A/AA، وإخفاء المساعد وتعطيل المسار عند إيقاف الإعداد، وعدم ظهور التوكن في HTML. اختُبرت أخطاء المدخلات والأصل والحصة والتوازي، ولم تظهر أخطاء JavaScript.

نجحت 22 حالة توافق إضافية للهيدر والصفحة الرئيسية والقوائم ودليل الخدمات. هذه النتائج لا تثبت جودة النموذج الحقيقي أو زمنه؛ لا توجد مفاتيح Cloudflare حقيقية في بيئة الاختبار، ولم تُرسل استدعاءات إلى حساب فعلي.

## تحديث أسلوب الحوار ومعرفة الموقع الجغرافي

بعد بلاغ المستخدم عن إجابات جافة ومتكررة، صارت تعليمات الحوار تؤكد الإجابة المباشرة الدافئة، وفهم التصحيح وأسئلة المتابعة، وعدم تكرار الخواتيم أو سؤال توضيح سبق أن أُجيب عنه. يُفهم «أين موقعكم؟» كسؤال جغرافي عادة، مع تمييز طلب رابط الموقع الإلكتروني الصريح.

مصدر التواصل يقرأ الموقع والاسم القانوني وقنوات الاتصال من إعدادات الموقع العامة نفسها. يتضمن السياق هذا المصدر في كل دور مع تعريف الشركة، وتُثبّت صفحة التواصل ضمن الروابط ذات الصلة لأسئلة الموقع والعنوان والهاتف والرجوع إلى جهة. لا يُفترض العمل عن بُعد أو وجود مكتب/عدم وجوده أو استقبال زوار من مجرد غياب عنوان شارع. المدينة والدولة لا تعنيان عنوانًا كاملًا أو إذن زيارة.

لوحظ في صفحة التواصل المنشورة وجود إسطنبول/تركيا وقنوات الاتصال، ولم تكن هذه المعلومات تُرسل سابقًا للمساعد. لا تُثبت هذه الملاحظة عنوان شارع أو ساعات استقبال؛ هذه البيانات تبقى من مسؤولية إعدادات الموقع وتأكيد المالك.

نجح البناء و247 اختبار وحدات بعد التحديث. أثبت فحص متصفح محلي للأسئلة «أين موقعكم؟» و«أقصد الموقع الجغرافي» و«هل يوجد مكان للرجوع إليه؟» وصول المدينة والدولة والهاتف والبريد وتعليمات الحوار في الأدوار الثلاثة، وتثبيت رابط التواصل، والاحتفاظ بالسياق وإمكان فتح صفحة التواصل. كان مزود النموذج محاكى؛ لا تمثل هذه الاختبارات حكمًا على صياغة Qwen الحقيقية، التي تُراجع بعد النشر باستخدام حساب المالك المفعّل.
