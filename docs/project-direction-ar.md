# قرارات اتجاه TEVONIQ

آخر تحديث: 25 أكتوبر 2026، وفق تعليمات صاحب الموقع.

- السوق المستهدف: المنشآت الصغيرة والمتوسطة في السوق العربي كله.
- التشغيل الحالي: المؤسس يعمل بنفسه بمساعدة الأدوات الحديثة والذكاء الاصطناعي؛ لا توجد أعمال عملاء يُدّعى تنفيذها.
- المؤهل وفق إفادة المؤسس: هندسة حاسب، جامعة أريل، إسطنبول.
- التطوير والمحتوى الجديد: العربية والإنجليزية فقط. لا نضيف محتوى تركيًا أو نوسّع النسخة التركية. لا يعني ذلك حذف محتواها الحالي أو تعطيل مساراتها دون طلب صريح.
- المدخل الافتراضي: `/ar` عندما تكون العربية مفعلة، مع احترام اختيار الزائر الصريح المحفوظ بموافقته. تبقى المسارات الإنجليزية والتركية الحالية متاحة. لا يعاد ضبط إعدادات CMS أو بياناتها ضمن هذا التعديل.
- بيستو: المؤسس هو صاحب البرنامج ومؤسسه، وفق تأكيده. يجري تجهيز التحميل، ويتوقع جاهزيته خلال يومين من 25 أكتوبر، أي نحو 27 أكتوبر 2026. هذا تقدير داخلي، وليس وعد نشر أو موعدًا يفعّل التحميل تلقائيًا. تظهر الحالة المتحققة فعلًا عند الإطلاق.
- لا تُعامل منتجات المؤسس كمشروعات نفّذها لعملاء. يمكن أن تكون دليل قدرة عندما تُعرض وظائفها الفعلية وحالتها بدقة.

توصيات إعادة كتابة الرئيسية والتنقل والخدمات في ملف الجرد لا تنفذ تلقائيًا. يراجع المؤسس المقترح قبل اعتماد المحتوى الجديد.

التحقق من تعديل المدخل: نجح بناء الإنتاج وجميع الاختبارات الـ185. فحص HTTP مع إعدادات اختبار افتراضية إنجليزية أثبت أن الزيارة الجديدة تذهب إلى `/ar`، وأن تفضيل الإنجليزية دون موافقة يُتجاهل، وأن الاختيار الصريح المسموح بحفظه يوجّه إلى `/en`. لم تُعدّل قاعدة البيانات أو محتويات الصفحات التركية.
