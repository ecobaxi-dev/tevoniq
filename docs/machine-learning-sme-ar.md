# الذكاء الاصطناعي وتعلّم الآلة للمنشآت الصغيرة والمتوسطة

## النطاق والتصميم

طُوّرت الخدمة القائمة `/ar/services/ai-machine-learning` ونظيرتها الإنجليزية، مع بقاء صفحة الاستشارات العامة `artificial-intelligence` وبقية فروع الذكاء الاصطناعي كما هي.

استُفيد من توزيع صفحة <https://www.n-ix.com/machine-learning-ai/>: هيرو أبيض ورسمة على خلفية برتقالية، فوائد عملية، ثلاث دراسات، رحلة تبنٍّ، مساران لاستراتيجية جديدة أو مراجعة حل، قدرات وأسئلة شائعة. النصوص والرسوم أصلية ومطوّعة لنطاق TEVONIQ. لا تُنسب أعمال المرجع أو عملاؤه أو نتائجه أو منهجيته إلى الشركة، ولا توجد روابط أو وسائط خارجية داخل القسم.

العنوان العربي «ذكاء يخدم أعمالك». العرض يركز على اختيار مهمة واحدة وتجربة نهج جاهز أو قواعد بسيطة قبل اقتراح تدريب نموذج مخصص. لا وعود دقة أو وفر أو ادعاء فرق أو اعتمادات أو شراكات. لم تُستعد الخدمات المتقاعدة أو عروض توسعة الفرق أو منصات البيانات والتحليلات.

## المحتوى

- ثلاث فوائد: الوصول إلى معلومة من محتوى معتمد، فرز الطلبات للمراجعة، وتقدير احتياج عند توفر بيانات مناسبة.
- ست قدرات: اختيار الاستخدام، مساعد معرفة، فهم النصوص، تقدير محدود، ربط المخرج بسير العمل، والتقييم والتحسين.
- أربع مراحل باختيارات أصلية تعمل دون JavaScript: فهم المهمة والبيانات، نموذج أولي، ربط بعد القبول، ومراجعة قبل التوسع. تتضمن كل مرحلة العمل والإجراءات والمخرج.
- دراسات سيناريوهات لمنشآت افتراضية: دليل إجراءات للصيانة، فرز رسائل مكتب أعمال، وتقدير احتياج متجر. تشرح المشكلة والنهج والبيانات ومعيار التقييم والحدود. ليست أعمال عملاء أو نتائج فعلية.
- نماذج الصيانة والتقاط الاستفسارات والمخزون المرتبطة تعرض سير العمل فقط، ويُشرح صراحة أنها لا تنفّذ ميزات الذكاء الاصطناعي المقترحة.
- مسار لتجربة فكرة ومسار لمراجعة حل قائم، وحدود وصول ومراجعة بشرية وتكلفة، وستة أسئلة شائعة مع بيانات FAQ منظمة.

## مرشد البداية

مكوّن تفاعلي صغير بثلاثة اختيارات: المهمة، جاهزية البيانات، وإذن استخدامها. يعمل بقواعد ثابتة معلنة، لا بنموذج ذكاء اصطناعي. يُعطي واحدة من أربع بدايات:

1. حسم الإذن وحدود الوصول قبل أي نقل بيانات.
2. مراجعة البيانات والجدوى عندما لا تتوفر عينة مناسبة، أو عندما تكون سجلات التقدير أولية فقط.
3. تجربة محددة بمراجعة بشرية لمساعد معرفة أو فرز طلبات.
4. مقارنة تقدير الاحتياج بخط أساس بسيط وفترة تقييم مستقلة، بعد التأكد من كفاية السجل.

التوصيات لا تمثل عرض سعر أو فحصًا فعليًا للبيانات. لا إدخال حر أو رفع ملفات أو تخزين اختيارات أو إرسال تلقائي أو استدعاء مزود ذكاء اصطناعي. تُمسح النتيجة عند تغيير اختيار لمنع استخدام نتيجة قديمة، مع زر إعادة بداية وإعلان نتيجة لتقنيات المساعدة. تعمل الدراسات والمراحل والمحتوى دون JavaScript، ويظهر شرح لاحتياج المرشد إليه.

## التكامل

القالب الجديد يخضع لشرط نشر الخدمة الحالي، وبقيت التركية على القالب السابق. حُدّث ملخص دليل الخدمات وبيانات SEO ومعرفة مساعد الموقع تحت شرط النشر نفسه. لم تتغير تعليمات المساعد أو مزوده أو مفاتيحه أو معلومات المقر.

تُقبل سياقات التواصل المعتمدة فقط: `ml=review`، و`ml=case-{id}`، و`ml=scope-{id}`، أو `ml=guide` مع ثلاث قيم معتمدة لـ`goal` و`data` و`access`. تُرفض القيم المجهولة أو المتعددة أو الناقصة. حوفظ على أولوية سياقات التواصل السابقة. الرابط يجهز الرسالة ولا يرسلها.

الرسوم HTML وSVG وCSS مع أيقونات النظام القائم، دون تحميل نموذج أو صور جديدة أو مكتبة رسوم إضافية. يحترم الرسم تقليل الحركة، وتظهر تفاصيل المراحل كلها عند غياب دعم `:has`.

نقطة الرجوع `checkpoint/pre-machine-learning-20261030` تشير إلى `273b3e7` قبل التعديل. لا تغيير على بيانات الإنتاج أو إعدادات الخدمة أو قاعدة البيانات أو حالة CMS. الرفع إلى `main` يجهز التحديث للنشر اليدوي عبر Render.

## التحقق

نجح البناء وفحص ESLint و254 اختبار وحدة. تغطي الاختبارات أولوية إذن البيانات وجاهزيتها، وجميع تركيبات المرشد، ومرور الاختيارات المعتمدة إلى التواصل ورفض غير المعتمد، ووجود النماذج المرتبطة وحدود الدراسات.

نجح فحص Chrome المخصص بالعربية والإنجليزية: شرط النشر، وثلاث دراسات وست قدرات، ومراحل التنفيذ بلوحة المفاتيح، وجميع تركيبات المرشد الـ18 لكل لغة، وإعادة البداية وتعبئة التواصل ورفض القيم غير المعروفة. اجتازت الصفحة عروض 320 و390 و768 و1024 و1440 وفحص axe A/AA وتقليل الحركة. بقي العنوان في سطر واحد داخل عموده على الكمبيوتر. اختُبرت المراحل والدراسات والمحتوى دون JavaScript وبقاء التركية على القالب السابق. لم تظهر أخطاء متصفح أو طلبات تواصل تلقائية أو استدعاءات لنموذج ذكاء اصطناعي.

نجحت اختبارات التوافق الـ81 في Chrome، بما فيها دليل الخدمات والتنقل والرئيسية والخدمات والنماذج الحالية وإنفاذ الخدمات المتقاعدة. حُدّثت بيانات دليل الخدمات المعزولة في الاختبار لتضم بطاقة الذكاء الاصطناعي وتعلّم الآلة وملخصها الحديث. تأكد وجود المسار العام الحالي باستجابة HTTP 200 قبل النشر؛ لا يعني ذلك أن التصميم الجديد نُشر على الاستضافة.
