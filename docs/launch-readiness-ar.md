- حساب الإدارة المحلي يستخدم البريد `kallas.hossam@gmail.com`. كلمة المرور العشوائية محفوظة في `.data/local-admin-credentials.txt` بصلاحية ملف خاصة، ومستثناة من Git وDocker وحزمة المصدر. لا تستخدم الحساب المحلي أو ملف بيانات دخوله في الإنتاج؛ أنشئ حساب إنتاج مستقلًا.

لإعادة التشغيل على هذا الجهاز:

```sh
export PATH="/opt/homebrew/opt/node@24/bin:$PATH"
npm run dev
```

يحتاج المشروع PostgreSQL يعمل محليًا. فحص الجاهزية: `http://localhost:4000/api/v1/health/ready`، وفحص الواجهة: `http://localhost:3000/health`.

## ملفات التشغيل والنقل

- `scripts/import-homepage.mjs --apply`: تهيئة الرئيسية محليًا دون استبدال محتوى موجود.
- `scripts/import-company-pages.mjs --apply`: تهيئة صفحات الشركة محليًا دون استبدال المحتوى.
- `scripts/import-company-contact.mjs --apply`: تحديث بيانات الشركة، مع نسخة احتياطية للإعدادات.
- `scripts/editorial-transfer.mjs`: تصدير ومراجعة واستيراد المحتوى إلى قاعدة فارغة؛ التعليمات في [DEPLOYMENT.md](../DEPLOYMENT.md).
- `.data/release/editorial-2026-10-22.json`: حزمة المحتوى المحلية الحالية؛ تحتوي على المسودات والمنشورات وإعدادات الشركة، وتحتاج مراجعة قبل استخدامها في الإنتاج.
- `.data/backups/tevoniq-prelaunch.dump`: نسخة قاعدة التطوير الكاملة. تتضمن الحساب المحلي؛ ليست حزمة نقل محتوى للإنتاج ولا تدخل في حزمة المصدر.
- `artifacts/release/tevoniq-source.tar.gz`: حزمة المصدر والأصول العامة، دون ملفات البيئة الفعلية أو بيانات الدخول أو النسخ الاحتياطية أو الاعتماديات المثبتة. ملف `SHA256SUMS` بجانبها للتحقق. لإعادة إنتاجها بعد أي تعديل: `python3 scripts/package-release.py`. ليست نسخة موقع ثابت تُرفع إلى public_html؛ تحتاج بناء وتشغيل خدمات Node وقاعدة البيانات.
- `scripts/check-release-env.mjs <api-env-file> <web-env-file>`: فحص إعدادات الإطلاق دون طباعة القيم السرية. أمثلة الإنتاج الحالية تفشل عمدًا حتى تضبط قاعدة الإنتاج وS3 وSMTP.

## خيار المعاينة المجانية الذي اختاره المالك

أُعدّ `render.yaml` لخدمة ويب واحدة وقاعدة PostgreSQL بخطة Free، مع تشغيل الواجهة وAPI داخليًا وتعطيل رفع الملفات غير الدائم والبريد. ملف التهيئة نُفذ واختُبر محليًا، لكن لم تُنشأ خدمة Render بعد لأن الحساب ومستودع GitHub لم يُربطا بعد. تختلف هذه المعاينة عن بنية الإنتاج السابقة؛ التفاصيل في [دليل Render المجاني](render-free-ar.md). قاعدة Render المجانية تنتهي بعد 30 يومًا، ومنافذ SMTP المعتادة محظورة عليها.
