# الأتمتة الذكية وربط الأعمال

## الصفحة

- العربية: `/ar/services/business-automation`.
- الإنجليزية: `/en/services/business-automation`.
- أُبقي مسار الخدمة الحالي وشرط نشرها من نظام المحتوى. النسخة التركية تعرض محتواها السابق.
- مرجع التكوين البصري: https://www.n-ix.com/intelligent-automation-services/، وخصوصًا جزء `Your intelligent automation journey with N-iX`.
- المحتوى مصاغ باسم TEVONIQ للمنشآت الصغيرة والمتوسطة، دون نقل ادعاءات العملاء أو الأعداد أو الشهادات أو إعادة الخدمات المحذوفة.

## التصميم والتنقل

- هيرو برسم مسار خفيف مبني بالكود: طلب، قواعد وموافقة، إجراء معتمد أو استثناء يحتاج مراجعة.
- فوائد عملية، وقدرات الربط، وستة أمثلة مرتبطة بصفحات محاكيات الأتمتة الموجودة.
- رحلة من خمس مراحل: فهم العمل، النطاق والخطة، التصميم والربط، الاختبار والتشغيل، المراجعة والتحسين.
- مراحل متناوبة على الكمبيوتر، مع انعكاس الاتجاه بالعربية، وأرقام دائرية كبيرة بتدرج برتقالي وردي ومسار يتقدم مع التمرير.
- المسار يحسب مواضع الأرقام وحدود المراحل الفعلية ويتكيف عند فتح التفاصيل أو تغيير المقاس؛ على الجوال تصبح المراحل عمودًا واحدًا.
- وصف كل مرحلة ومخرجها يظهران دون JavaScript؛ التفاصيل والأسئلة الشائعة تستخدم عناصر HTML أصلية قابلة للفتح بلوحة المفاتيح.
- إعداد تقليل الحركة يعرض المسار كاملًا دون تحريك، ويوقف حركة الرسم والانتقالات.
- روابط المناقشة تنقل رسالة أولية قابلة للتعديل إلى التواصل باستخدام معرف مرحلة معتمد فقط؛ لا ترسل رسالة تلقائيًا ولا تنقل بيانات زائر حرة في الرابط.

## حدود العرض

النماذج توضيحية ببيانات افتراضية. لا توجد تكاملات فعلية أو رسائل خارجية من الصفحة. الربط الحقيقي يتطلب مراجعة واجهات البرامج والصلاحيات والشروط والتكاليف، واعتماد الاختبار والتشغيل. لا وعود بنتائج رقمية أو دعم غير محدد النطاق. لا روابط خارج الموقع أو نسب محتوى لمصدر خارجي ضمن الصفحة العامة.

## التحقق

- بناء Next.js والتحقق من الأنواع.
- اختبارات وحدات لمسار الربط، وتقييد تقدم التمرير، والتحقق من معرفات المراحل ورسائل التواصل.
- اختبارات متصفح بالعربية والإنجليزية: شرط النشر، انعكاس المراحل، تقدم المسار، إعادة المحاذاة عند فتح التفاصيل، والتواصل دون إرسال تلقائي.
- مقاسات 1440 و1024 و768 و390 و320 بكسل، وفحص إتاحة WCAG عبر axe للحالة العادية والمفتوحة، والعمل دون JavaScript وتقليل الحركة، والحفاظ على التركية.
- تشغيل اختبارات الصفحات والنماذج السابقة قبل التسليم.
