# معرض مواقع الأعمال

أضيفت ستة تصاميم توضيحية بالعربية والإنجليزية، مرتبطة ببطاقة «مواقع الأعمال» في الصفحة الرئيسية:

| النموذج       | صفحة التفاصيل                           | التفاعل في المعاينة                                     |
| ------------- | --------------------------------------- | ------------------------------------------------------- |
| لِين للأثاث   | `/ar/website-designs/furniture-atelier` | صور متبدلة، تصنيفات، سلة، اختيار خامة ومقاس، طلب توضيحي |
| رواق ستور     | `/ar/website-designs/retail-store`      | تصنيفات، سلة، كميات، طلب توضيحي                         |
| ركائز للصناعة | `/ar/website-designs/industrial`        | تصفية القدرات وطلب منظم                                 |
| أفق للعقارات  | `/ar/website-designs/real-estate`       | تصفية العروض، حفظ مؤقت، طلب معاينة                      |
| نماء          | `/ar/website-designs/agriculture`       | صناديق موسمية، تصفية وسلة وطلب توضيحي                   |
| وجهة للخدمات  | `/ar/website-designs/business-services` | تصفية الخدمات وطلب موعد                                 |

المعرض: `/ar/website-designs`. المعاينات: `/previews/ar/[slug]`، وبالمثل `en`. صفحات التفاصيل توضح الجمهور والصفحات والفائدة والربط والأتمتة وطريقة البيع. اختيار تصميم ينقل اسمه إلى رسالة التواصل القابلة للتحرير، دون تغيير معالجة الطلبات الحالية.

هذه هويات افتراضية وليست أعمال عملاء. السلة والحفظ والنماذج داخل المعاينة مؤقتة في ذاكرة الصفحة؛ لا يوجد دفع أو إرسال طلب أو حجز فعلي. ربط المخزون والمحاسبة وCRM والتقويم والدفع والشحن يحتاج حسابات وصلاحيات وواجهات موثقة واتفاقًا مستقلًا على النطاق. الأسعار والمنتجات والصور توضيحية. المعاينات غير مفهرسة، بينما المعرض والتفاصيل ضمن خريطة الموقع للعربية والإنجليزية فقط.

## التحقق ونقطة الرجوع

- نجح بناء `@tevoniq/web` وفحص ESLint للملفات المعدلة دون تحذيرات.
- نجحت الاختبارات العامة الـ194 واختبارات المتصفح الـ14 للصفحة الرئيسية والمعرض والمعاينات.
- شمل الفحص تحميل الصور، العربية والإنجليزية، مقاسات 1440 و390 و320، السلة والمقاسات والطلبات المحلية، تعبئة التصميم في التواصل، الروابط وصفحات 404، عدم الفهرسة للمعاينات، التصفح دون JavaScript، الإتاحة وفق WCAG والحركة المخفضة ولوحة المفاتيح.
- نقطة الرجوع قبل التغيير: `checkpoint/pre-website-design-gallery-20261026` عند `6190d1f`. النشر الفعلي عبر Render خطوة مستقلة.
