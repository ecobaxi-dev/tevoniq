# تحسين رسائل الطلبات وبيانات التواصل — 2 نوفمبر 2026

## التغييرات

- قالب بريد HTML جديد للعربية والإنجليزية لرسائل تأكيد التواصل وطلب عرض السعر، مع نسخة نصية بديلة. معالجة سبب وصول العربية كنص فقط: تفعيل HTML للعربية في عامل البريد.
- هوية كحلية وسماوية، رسالة شخصية، حالة الطلب، رقم مرجعي واضح، خطوات المتابعة وزر للتواصل. لا صور خارجية أو JavaScript؛ تستخدم الرسالة جداول وأنماطًا مضمنة لتوافق عملاء البريد، مع خلفيات بديلة عند عدم دعم التدرجات.
- عزل الرقم المرجعي باتجاه LTR في البريد والنموذج لمنع اختلاط أجزاء UUID بالنص العربي. قد يلتف المرجع على الشاشات شديدة الضيق دون تغيير محتواه.
- قائمة بلدان بأسماء عربية/إنجليزية ورموز الاتصال في نموذجي التواصل وعرض السعر. لم تُضف واجهة تركية جديدة؛ بقيت الواجهة التركية القائمة.
- تحقق مشترك في الواجهة وAPI باستخدام بيانات الترقيم الكاملة من libphonenumber-js/max. رفض الأرقام المخالفة لقواعد الترقيم قبل الحفظ، وقبول الأرقام العربية والفارسية والمحلية والدولية وتحويلها إلى E.164. تخزين البلد برمز ISO من حرفين، مع دعم أسماء البلدان القديمة المعروفة لتوافق العملاء السابقين.
- يبقى الهاتف اختياريًا للتواصل بالبريد، وإلزاميًا لعرض السعر أو اختيار التواصل الهاتفي. يمكن استخدام رقم دولي يختلف بلده عن بلد المنشأة.

## الحدود والنشر

التحقق يثبت توافق الرقم مع خطة الترقيم، ولا يثبت أنه نشط أو يملكه مقدم الطلب. إثبات الملكية يحتاج OTP. السجلات القديمة لا تتغير ولا يلزم ترحيل قاعدة البيانات. يجب نشر API وWeb معًا وتثبيت الاعتماد من package-lock.json. تبقى إعدادات المرسل وSMTP وReply-To الحالية دون تغيير. لم يُرسل بريد فعلي ولم تُستخدم قاعدة الإنتاج للاختبار. المعاينة في Chrome لا تعادل اختبار تسليم فعلي في Gmail أو Outlook؛ الشكل قد يختلف بحسب عميل البريد.

## التحقق

- بناء API وWeb وفحص ESLint.
- اختبارات القوالب، HTML escaping، RTL وعزل المرجع، عامل البريد العربي والنسخة النصية.
- اختبارات الأرقام غير الصالحة وتطبيع رقم سعودي مكتوب بالأرقام العربية، وتوافق أسماء البلدان السابقة، واختبار رفض API قبل لمس التخزين.
- اختبار المتصفح لنموذجي التواصل وعرض السعر بالإنجليزية، وللنموذج العربي مع رفض رقم خاطئ دون إرسال ثم إرسال الرقم الصحيح مطبعًا إلى API وهمية.
- معاينة البريد بالعربية والإنجليزية على عرض 375 و800 بكسل دون تمرير أفقي.
